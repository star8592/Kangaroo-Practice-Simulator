# 100-problem verification pilot

Target mix:
- 30 AMC/AIME algebra
- 25 AMC/AIME number theory
- 20 middle-school algebra
- 15 inequalities
- 10 mixed proof-oriented problems

For every problem record: source id, normalized statement, expected answer, formal statement, proof source, verification result, attempts, runtime, failure class.

Success metrics: formalization rate, first-pass Lean verification rate, auto-repair rate, unsupported rate, median verification latency.
