# SOC THINK Agent 工程课程：真实代码作业 R1（2026-11-04）

## 核心变化

课程入口 `/skill-labs/agent-foundations` 保留已有六节基础课、六个知识检查模块及原始可下载 Python 演示；现在通过一个可见的「开始真实代码作业 · 4项 / 16组测试」入口，进入既有 `/skill-labs/engineering/agent` 动态工程实训路由。不是新建孤立页面、第二个学习系统或 ZIP 单卖。

新增 JavaScript 版 Agent 工程关键逻辑训练，四项都是实际编写函数、由浏览器的 QuickJS WebAssembly 虚拟机执行：工单输入契约、多意图分类、受控动作授权、事件幂等去重。每项四组实际用例（共16），包括异常/恶意输入；错误代码不得放行。四项参考实现及故意编错的实现均由独立 Node 单元测试通过验证。与原有前端/后端/QA 12 项和初始通用 6 项共用同一个 Worker、运行时限制与安全清理流程；不引入新的服务器执行任意学生代码。

**语言和权利边界**：工程代码训练是 JavaScript 版本的关键逻辑实现，与 Python 离线完整项目教材相互补充，网页没有运行 Python。所有用例由前端提供，不能充当监考、职业认证或防作弊的正式成绩。Worker 无网络、DOM 和 Node 权限，QuickJS VM 内存 16MiB，每组运行至多约850ms，Worker 总超时12s，源码最多5000字符。既有规则保留。

## 已验收的用户体验

从课程开始→转入 Agent 工程作业→明确同意离线隔离执行→修改 JavaScript 函数→运行四个真实用例→看到通过数、具体错误和样例→通过才进入下一题→完成后可查看并打印本标签页实操记录。

新增 Playwright 桌面/手机 E2E 覆盖课程→实训的真实点击、错误代码拒绝、正确实现通过、下一任务的条件解锁、390px 无横向溢出。与原来课程和职业路线浏览器测试互不替代。

## 仍需独立完成

1. **服务器独立核验**：浏览器测试成绩可被用户篡改，不能据此授予账号等级、认证或收费权益。正式课程必须有隔离的服务器端代码执行服务（网络禁用、CPU/内存/时间硬限制、最小权限、提交频率限制、可信结果签名），将题目用例/评分版本独立留在服务端。
2. **微信账号档案**：完成服务端可信评分后，复用现有 `WECHAT` 学习身份、私有用户数据根和账本，保存每次源码摘要、成绩、题目版本、真实测试回执、提交时间，而不是收集源代码或把 localStorage 当信用记录。
3. **正式课程报告**：从实际运行证据及错误类型生成可追踪的能力雷达、返工任务与下一次复测建议；当前仅浏览器本标签页练习记录，不要显示专业证书或就业概率。
4. **收费**：项目作业独立评分、账号回执和课程权益履约都通过验证后，再创建明确的按课程付费和按月服务 SKU，复用唯一 Native 微信账本。之前的 ZIP ¥4.90 单品已取消，不应复活。

## R2：服务器独立复测与微信学习记录（本分支，未完成生产验收）

**沿用 R1 的唯一入口** `/skill-labs/engineering/agent`、原 4 项 JavaScript 作业、16 组用例、现有 `CodeLabClient` 和 Worker。不会新建第二个编辑器或并行题库。

学生仍然可以匿名免费在浏览器执行代码；当微信账号已验证且学生**主动点击“提交并保存”**时，浏览器才向 `/api/skill-labs/engineering/agent/attempts` 上传当前源码。服务器通过 QuickJS/WASM 再次执行相同用例，用实际结果生成摘要，完全忽略请求携带的成绩、用户 ID 或完成状态。写入的学习历史归属 `userFromRequest` 认证用户，不相信前端指定归属。

- 已记录：题目 ID、评分版本、通过数/总用例数、是否全部通过、提交时间、随机提交 ID、源码 SHA-256 指纹。
- **不记录**：原始学生源码、用户在代码里误填的密钥、真实工单、支付信息。服务器实际执行仍会临时读取源码；浏览器须说明上传发生的条件。
- 持久化复用 `SOCTHINK_USER_DATA_DIR`（原站点私有用户目录），一个微信账号一个隔离目录、文件 0600、目录 0700、原子发布、同提交 ID 重放幂等、不同内容冲突拒绝。
- 新 API 限同源、校验长度、只能访问既定 Agent 编程任务、依靠已有 Web 微信身份；短窗口节流仅为单机防误操作，不声称具备分布式流控能力。
- 历史是可跨设备查询的 **形成性代码训练回执**；前端试卷公开、无防作弊、无职业认证，不代表生产级 Python 多文件项目。
- 本分支加入 `scripts/test_agent_code_account_api.ts`，检查游客拒绝、自报成绩无效、回放一致、跨账号隔离、服务器判分、磁盘权限与不保存源码。

**特别说明**：现阶段服务器重新执行的是 JavaScript 纯函数，不是 Python 工单项目；当前 16 组测试也是公开形成性用例。未来商业收费版必须另外验收可信服务端隐蔽/留出测试集、独立受限 Python 执行沙箱、权限权益、反馈报告和微信支付真实履约。R2 不启用任何课程 SKU、付款或权益。
