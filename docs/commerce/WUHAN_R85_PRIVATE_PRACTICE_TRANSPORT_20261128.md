# R85 主站私有评分传输
复用现有Node HTTP、HMAC与既有冻结题库。仅接受数值回环端口、固定题目、合法音频容器、2MiB以内录音；签名绑定原始字节、时戳、随机nonce与题目。服务端密钥文件需私有权限、拒绝符号链接。返回校验nonce、题目、音频摘要格式、预期规则版本、非官方非计费标记及短答练习点一致性；不自动重试付费或写入成绩，不公开浏览器路由。现有研究报告和用户数据不变。
测试185920：真实HTTP模拟对端核对签名，6类无效响应及7类本地无效请求拒绝，TypeScript通过。185926：主站实际Node传输到新Rust私有评分程序并处理合成语音，正确短答、版本一致、非计费，退出0。185901：真实云主机经临时SSH回环通道访问Z890，三类录音及非法签名、nonce复用测试通过。旧评分服务仍连接。当前无常驻新服务、无正式浏览器入口和真实用户数据；需要现有账户/监护授权与资源限流接入，不能把内部调用当成上线。模型冷启动17–32秒样本需要优化；完整模型依赖版本冻结及重启nonce防护仍待完成。不新增教师评分条件。
