# 统一渠道卡券：用户确认方案，2026-11-27
外部电商优先采用平台批准的虚拟卡券履约，官网微信直接付费。统一账户、商品、权益与账本，不新增独立用户或支付系统。
本轮仅开发并验证隔离卡券原语；未安装数据库、未启用接口、未生成真实卡券、未开售。

## 订单与激活
- 渠道商户+订单行+购买件序号唯一；数量N发N个独立卡券。渠道SKU映射至内部不可变商品权益快照。
- 平台官方签名及独立订单查询确认实付、币种、商品、数量、商户后方可发券。未绑定账户的订单暂进入中央账本所属外部订单收件/待认领区；不能创建虚假微信账户。对账统计须含未认领订单且防重复入账。
- 每券高熵、服务端独立密钥衍生、支持版本化；发货重试返回同一券。数据库仅保留查找摘要、版本、订单关联、状态；独立密钥存于现有服务端密钥系统，轮换保留未到期版本。不得在日志输出券码。平台若要求自有券码，另写适配器，不假设本编码适用。
- 使用平台允许的激活/核销渠道；服务端认证当前账号和学生归属。核销以事务锁完成，中央订单入账和权益同事务，失败全部回滚。同账号重试不重复发权益，跨账号拒绝；未授权、退款、过期拒绝。
- 平台退款请求须先处理争议和核销状态，以官方确认的退款事实撤销未用券或未来服务权益；保留学习历史与财务审计。部分退款按订单行/件归属精确处理；核销与退款并发串行化。退款回原收款渠道。
- 卡券不是现金、余额或可转账资产，只对应确定的单次教育服务权益。机构批量卡后续按实际席位规则实现，不直接把个人券当组织授权。
- 未激活提醒、重新发送仅通过批准的平台能力；不收集多余个人信息，不以私信或二维码绕过平台限制。
