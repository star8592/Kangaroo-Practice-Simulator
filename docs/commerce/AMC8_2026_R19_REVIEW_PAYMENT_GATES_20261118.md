## 4. 发布封锁原因

- 原卷及翻译的商业使用许可未确认。官方公布存在简体中文版不等于第三方有权售卖。
- 25道译文、125选项、图形、公式、解析尚未获得逐题独立最终签核。
- CommerceFlow 真正支付闭环不完整；目前月卡在创建 License 任务时仍直接拒绝（`AMC8_MONTH_NOT_READY`）。
- 独立 HTTPS 发布与真实闲鱼卖家订单/IM交付回读无最终证据。

以上任何一项未通过，继续保持 GitHub Draft，维持权益发放 fail-closed；可使用纯合成题在本地验证自动化链路，但不能向真实买家交付未授权真题。
