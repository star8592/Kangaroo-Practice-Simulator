# AMC 8 R21：真实交易身份幂等与授权通路同步

日期：2026-11-19。**内部草稿 / NOT LIVE / NOT FOR SALE**。

## 本轮已实测技术变化

CommerceFlow PR #379 修复了月卡结算错误地使用短时卖家观察证明作为幂等唯一身份的问题：

- 稳定 sale_sha256 仅覆盖成交订单ID、SKU、买家、具体月卡规格、实际付款时间和实际付款金额；
- 新的每次读取时间戳/HMAC另外验证，且包含稳定哈希、原始观察快照哈希；
- 同一笔成交重新读取可幂等，原始买家/规格/付款时间/金额变化被拒绝；
- 调用真实 Node.js HMAC 签名函数，给 Python License 验证器传递两次不同签名的相同合成成交，SQLite只入一笔结算；
- 现有月卡 SKU 仍拒绝任何生产发权，模拟交易测试绝非实收款。

CommerceFlow 详细记录：docs/AMC8_R21_STABLE_MONTHLY_SALE_IDENTITY_20261119.md。
