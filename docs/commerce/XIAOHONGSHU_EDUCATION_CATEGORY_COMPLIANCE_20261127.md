2. 该规则明确：
   - “知识会员”“智能教育/学习卡”“游学/研学/留学”“留学”不支持个人店和个体工商户店入驻。

3. 《店铺入驻规则—教育行业》对英语语言培训列出至少一名教师的英语相关资质要求，例如英语学科教师资格、英语专业本科及以上、英语专四/专八、雅思/托福成绩、翻译/口译资格或CELTA等；企业入驻还要求营业执照经营范围涵盖教育咨询/培训，并提供教师与经营主体的劳动或合作关系证明。
   官方规则：https://school.xiaohongshu.com/rule/detail/17/193

4. 小红书店铺类型规则当前写明，个体店和个人店暂不支持直接变更为企业类型店铺。若未来必须走“智能教育/学习卡”企业店路径，应另行核验新开企业店主体资格，不得假定现有个体店可以直接升级。
   官方规则：https://school.xiaohongshu.com/rule/detail/823

## 类目判断

### 首选申请方向：儿童教育 → 语言培训 → 英语 → 国内考试英语

理由：
- 这是小红书商品页自动识别给出的路径；
- 商品服务对象、训练内容和考试用途与英语听说专项训练相符；
- 相比“智能教育/学习卡”，该子类目没有在2026教育定向规则中被明确列入“个体工商户店不支持”的四个特殊子类目，但仍需平台邀约审核及英语教师资质。
- 不能因为商品以卡券激活，就把教育服务改挂为普通“兑换券”。

### 暂不采用：儿童教育 → 智能教育/学习卡

虽然“学习卡”在商品形态上看似接近，但现有店铺为个体店，而官方规则明确该子类目不支持个人店和个体工商户店，并列示10万元保证金。未完成主体和平台审核前，不作为当前店铺的上架路径。

### 不采用：电子资源、普通兑换券、虚拟充值

- 电子资源的规则范围主要是PPT/模板、课件教案、手抄报、头像壁纸等数字文件，不等同于在线考试模拟软件服务。
- 普通虚拟卡券规则按平台列出的餐饮、本地生活、电影票等适用品类执行，不可用来规避教育定向准入。
- 不把真实教育服务包装成不相干的商品类目。
