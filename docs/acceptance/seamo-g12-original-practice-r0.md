# SEAMO 2026 · G1/G2 原创基础专项训练 R0 验收合同

## 定位与内容边界

- 本版本仅提供本站独立编写的 **原创基础专项练习**，不是 SEAMO 官方历年真题、官方样题或完整难度的仿真卷。
- 年级 1：Pre-A 练习，15 道选择题，训练计时 40 分钟。
- 年级 2：A 组练习，20 道选择题 + 5 道整数填答题，训练计时 90 分钟。
- 练习评分为本站自定义规则：每题 1 分，答错和空题均不扣分，满分分别为 15、25 分；**不得**宣传为官方计分。
- 赛事日期、报名资格及官方赛制以主办方当年通知为准；活动信息不是学生报名成功的证明。
- 当前题库主要覆盖数感、简单运算、规律、队列逻辑、基础几何。正式竞赛难度覆盖和人工审题仍属后续版本。

## 必须保持的行为

1. 竞赛中心显示独立的 SEAMO 入口，不能混入澳洲 AMC / 美国 AMC / 袋鼠数学赛制。
2. 一、二年级练习可分别打开；题量、选择/整数输入方式、计时和规则与上述配置一致。
3. 学生未登录不得获取试卷数据或提交成绩；登录后可以开始、作答、交卷和查看成绩。
4. 学生试卷 API 不能包含正确答案或解析；服务端独立评分，不接受重复提交同一会话。
5. 中英文题干、选项完整；一年级/二年级 Web 答题页提供按键朗读题目及选项、停止和进度条。语音由浏览器本地能力提供，不承诺所有微信内核都支持。
6. 现有赛事、权限和题库不回归；不改动主工作区的私有试卷和用户数据。
7. SEAMO 原创数据作为版本内资源打包，不依赖部署时会被替换的私有试卷目录。

## 自动验收

- `npm run test:seamo`：40 道题的独立数值校验、题型、题量、学生下发脱敏、全对/全错/空题计分，并验证无私有题库的干净 CI 环境。
- `npm run verify:public`：前端、登录、数据和生产构建回归。
- `npm run verify:full`：含私有数据和既有赛事的完整回归及生产构建。
- 预览 HTTP 烟测：两年级登录、获取题目、启动会话、交卷、重复提交拒绝。
- `tests/e2e/seamo-original-practice.spec.ts`：桌面和手机尺寸 Chrome 真实点击、登录、答题、提交及二年级整数题双语朗读控件。

## 发布门禁与回滚

- 代码提交并推送到 GitHub 后，以**准确的提交 SHA** 构建不可变预发布版本。
- 预发布版本须通过健康检查、题库可见性及真实页面交互检查，才能切换线上服务。
- 保留上一版可回滚链接；若上线后登录、竞赛列表、答题或评分失败，应立即回滚。
- 微信小程序目录暂仅提供 SEAMO 的 Web 训练链接，并明确说明原生 MP3 语音待完成；原生答题页未放行。
- 微信小程序需要独立构建、真机验收与微信审核；Web 发布成功不代表小程序发布成功。
- 浏览器音频实际可听性、Safari 和微信内核的兼容性，未完成验证时必须明确记录，不得声称已通过。
