# SOC THINK 微信统一身份：英语应用一次性票据（2026-11-12）

业务归属：仅国内 https://socthink.cn，完全隔离海外 Zoria。本阶段仅是主站的身份桥，不能声称四应用已经统一登录或历史档案已合并。

## 用户体验
- 首页、课程目录、免费内容先浏览；保存学习记录、交作业、购买或私有报告需要微信登录才调用统一 /login?next=原目标。
- 已登录用户不重复扫微信：各独立应用通过同域接口申请临时票据，应用后端兑换后建立自己的学习会话。
- 唯一收银台仍为主站现有微信支付与中央账本，应用不复制订单、商户密钥或支付通知。

## 新增主站 API
1. POST /api/english/sso/ticket。浏览器同源 JSON Body product=reading，必须携带已有的 HttpOnly 微信账号 Cookie；只向正式微信用户发放短票，不返回账户 ID。
2. POST /api/english/sso/redeem。只有产品后端携带其独立 Bearer 密钥才能兑换。Body product 和 ticket。成功得到仅属于该产品的稳定匿名 subject。
3. 四个受限产品：pronunciation、vocabulary、reading、aelos。有效期 75 秒。服务器文件原子领取、只消费一次；过期、伪造、跨产品或重复兑换全部拒绝。
4. 各产品分别配置长高熵私钥：SOCTHINK_ENGLISH_SSO_KEY_PRONUNCIATION、SOCTHINK_ENGLISH_SSO_KEY_VOCABULARY、SOCTHINK_ENGLISH_SSO_KEY_READING、SOCTHINK_ENGLISH_SSO_KEY_AELOS。无密钥默认拒绝；不进入源码或 GitHub。
5. 存在用户数据目录中的临时票据为权限私有文件；主体的 HMAC 稳定密钥须跨发布备份，不得随版本轮换，避免失去旧学习档案关联。

## 各应用后端接入合同
- 浏览器凭主站 Cookie 请求 ticket，票据传给对应应用的同源后端；浏览器从不看到后端认证密钥或微信标识。
- 后端向本机主站 127.0.0.1:3000 服务端兑换票据，不接受用户自己声称的账号、角色、付费标记。
- subject 只作为账号映射键。默认普通学生权限，既有账号必须经过双方认证后绑定，不能按昵称自动合并或冒充教师管理员。
- 每个应用保留自己独立 DB、音频和学习记录，并将产品 Cookie Path 限定为该英语应用目录。完成每产品实际登录、历史学习记录/音频、退出/过期、支付前后权限的真实验收才对外宣称 SSO 成功。
- 应用的有偿资源必须以主站可信权益核验结果判断，不得把 SSO 等同于已付费；主站退出后，应用私有敏感操作应重验授权而不是无限延长会话。
