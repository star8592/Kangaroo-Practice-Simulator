# SOC THINK 门户信息架构及首页动态内容（2026-11-03）

状态：本文件说明首页 V3 与统一搜索的代码设计；**正式上线只以生产 deployedSha 与实际访问通过为准**。

## 1. 根本问题（仓库审计事实）

原首页 \`src/components/PublicHome.tsx\` 停留在“考试搜索 + 3 入口 + 7 类考试目录”，缺少已经实际开放的技术书库、AI Agent、WebGPU/Three.js、SQL、JavaScript、岗位笔试、职业教程、9 项测评以及商城入口。
旧的 \`EXAM_DIRECTORY\` 又把已经开放的 SQL、Agent、模拟面试和职业探索错误标为规划中。部分页面仍用“从考试中心进入”作为职业、测评的面包屑；首页搜索仅跳向 \`/assessments\`，根本搜不到书籍、技能或商品。

## 2. 对外导航与层级（唯一服务视图）

首页 \`/\`：一屏内能搜索、看到可用入口、理解该站的真正服务。
2026-11-03 二轮纠偏：一级只保留六项真正独立的业务：\`/assessments\` 全部考试、\`/resources\` 真题资料、\`/career\` 职业岗位、\`/skill-labs\` 技能实训、\`/assessment-center\` 测评中心、\`/shop\` 数字商城。\`/exam-planner\` 和 \`/events\` 隶属考试业务；\`/skill-labs/books\` 隶属技能实训；所有旧 URL 均保持可访问。
2026-11-03 导航纠偏：**删除顶部与手机导航的“在线练习”独立菜单**。\`/arithmetic\`、\`/competitions\`、\`/review\` 是数学/K12 与竞赛的二级训练动作，已归入 \`/assessments\` 的考试/训练入口和首页快捷入口；保留原有路径、权限及成绩。顶部只保留七项真实业务栏目，不建立练习的平行顶级分类。
归属关系：技术书库 \`/skill-labs/books\` 为技能体系子层；Agent / Three.js / SQL / 编程皆属技能实训；岗位笔试及原创教程属 \`/career\`；心理和研究测评独立于正式职业资格和岗位考试；资料商城只展示实际在架商品，付费仍走单一账本。
考试目录只保留五类：校内升学、数学竞赛、语言考试、大学考研、资格公考。岗位实操与心理/职业兴趣研究已经迁回职业、技能、测评中心，不再混入考试导航。\`ASSESSMENT_DOMAINS\` 原七领域仍是底层测评 API 的数据契约，不能直接当作公众考试菜单；旧书签 \`#domain-career\` 和 \`#domain-interest\` 在客户端转到相应业务。
\`/search?q=...\` 是全站公开内容发现入口；不再复用考试搜索扮演全站搜索。搜索页 noindex，内容详情页保留原 canonical SEO URL。
个人账号、购买权益、订单与下载归在 SessionNav、移动端“个人服务”和页脚，不在最拥挤的第一层挤满入口。

## 3. 首页顺序与视觉准则

1. 有明确收益的单句 H1、全站搜索、6 个有结果的搜索示例；不用虚构会员数或收入。
2. 三个最高频动作：数学训练、竞赛模拟、试卷检索。
3. **最近更新**：直接使用原始内容源中的 \`updatedAt\` 或已证实的首次公开日期，而非访问时间或构建时间；真实书库版本、Agent 课程、WebGPU 课程、最新岗位模拟笔试、原创职业资料自动排序。
4. 首页四个并列业务卡：职业、技能、测评、商城；书籍和考试日程分别在技能与考试体系中呈现。
5. 两个内容更深入的展示：AI Agent 课程→模拟笔试，Three.js 交互实验→相关书籍。
6. 下方保留五类真考试索引，尚未开放的方向明确写出状态。
7. 按服务/学习/账号清晰分组的页脚；避免巨量废话、互相竞争的 CTA 和把“规划中”印成商品。

## 4. 数据源：一条主链路，不做第二 CMS

\`src/lib/site-discovery.ts\` 只读组装：
- \`TECH_BOOKS\`（书籍和官网来源；新增书目录入后有书库发布日期）
- \`CAREER_FORMAL_PAPERS\`（已经开放的完整岗位模拟）
- \`CAREER_ORIGINAL_GUIDES\`（免费正式原创资料，保留其 \`updatedAt\`）
- \`ASSESSMENT_EVIDENCE\`（已列出的真实测评与来源）
- \`AGENT_FOUNDATIONS_COURSE\` 与 \`WEBGPU_COURSE\`（各自 \`updatedAt\`）
- \`EXAM_DIRECTORY\`（仅可点击 \`live\` 项）
搜索运行时再调用**已有** \`listTrainingExamProfiles → buildTrainingResourceCatalog\` 与 \`listStoreProducts\`，展示经过训练可用性验证的试卷和真实在架数字商品；不暴露私有答案、支付凭据或客户信息。
对没有可信出版/上架时间的内容不显示伪造“刚刚更新”；后续要从商品账本、正式题库发行记录补充 \`publishedAt/verifiedAt\` 的受控只读投影，再扩大首页更新面板。

## 5. 旧内容处置原则

旧 URL 未逐个审计前不一刀切删除，也不新增平行路由。可用旧链接保持；有语义重复的入口只从导航撤除；经过使用/SEO/链接核查后再决定 301/canonical。不把已有学生登录、购物账户和付费边界重新做一套。
全站不把 planned 分类伪装成已开放考试；任何付费入口要求真实商品、实际交付和当前支付授权。书库免费阅读与文件下载仍分开核验。

## 6. 专项验收

- 首页动态更新顺序与内容源日期一致，2026-11-03 的书库和岗位笔试有真实入口。
- \`/search?q=Rust\` 展示技术书；\`?q=Agent\` 同时展示课程与岗位笔试；\`?q=AMC\` 检索相关考试/试卷；未知词显示明确空状态。
- 桌面和手机全局导航只呈现六个一级业务；考试管理必须从考试中心进入，技术书库隶属技能实训；不把岗位与人格研究放入考试目录。
- 首页五类真正考试可进入 \`/assessments#domain-*\`；历史 career / interest 锚点可跳转其所属中心；未开放考试不得进入可购入口。
- 无页面横向溢出，公共页面只有一个 h1 和主内容 landmark；现有登录/购买/考试用例正常。
- 上线以同 SHA CI、自动回退发布回执、公网 \`/api/release\` 精确 SHA 与人工可见真实 URL 检查共同确认。
