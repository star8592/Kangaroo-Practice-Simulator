# AccentLab R7C — 引导式情景问答（受控版）

日期：2026-11-20。接续已经上线的 R7A/R7B 学生端：**基础跟读、单词专项、情景问答三模式并存，基础跟读仍是默认入口**。不改变旧 V3、统一用户/计费、教师作业、Rust API 协议或原有成绩含义。

## 真实可用能力
1. 复用现有 Rust 9 句原创语料，每句绑定一个**人工编写、可审查的简短问题和中文理解提示**，来源见 `GuidedDialogueCards.ts`；不存在虚构的大模型自由对话接口。
2. 孩子点击「听问题」→ 设备 TTS 按所选 0.3 / 0.5 / 0.7 / 0.85 / 1.0 / 1.15 倍播放；未内置统一发音人，设备播放质量有差异。不会直接显示参考答案，孩子可以自主点击「我没听懂 · 看提示」「▶ 听参考答案」「看参考答句」。
3. 参考答案复用原语料音轨和已处理的 0.3×预渲染保音高音轨（故障时原有自动降级）；不替换音轨源。
4. 点击「我来回答并评分」后，**跳过基础跟读的自动先播参考音**，直接播放提示音、获取儿童录音、检测语音和停顿；沿用 R6 麦克风授权异步安全、真实 Blob 和 Rust `/follow-along/items/{id}/score`。服务端分数必须是有效 0–100 数字，否则不给分、不假装成功。孩子能自行再试或下一问。
5. 面板中的分数明确只表示**与绑定参考答句的发音匹配**。若孩子自由回答不同但正确的句子，现有声学模型可能给低分，所以界面明确**不判断自由回答的语义正确性**。只在 Rust 返回且与参考句确有匹配的高风险词时提示纠音，不凭空编语法或音素诊断。
6. 切换模式、换问后不保留上问评分；录音期间禁用模式切换，离开页面回收设备资源。原有所有跟读和单词回归不应下降。

## 诚实的产品定义
这是 **R7C 引导式情景问答第一版**，与固定答案进行真实评分和有限的下一步提示，**不属于生成式自由 AI 对话**。没有部署 LLM 对话 API、动态意图判断、儿童回答语义评分或教师作业持久化。大模型后续只有在有独立能力检测/安全边界/成本管理/儿童数据保护、中文儿童测评集之后才接入；不应因为 UI 像聊天就宣称具有上述能力。

## 安全与验收
- 不接受外部 prompt 注入任意任务；问答卡片固定并可审计。
- 没有麦克风权限、录音太短、服务端 503、分数无效时，不造分、不把自由回答错判为语法错误。
- 录音发送原有自托管接口，上传说明保持可访问。
- 桌面/移动 Playwright 新增：问题/TTS/中文提示/参考答案渐进展现、0.3x 音轨、真实录音与 API 对应、下一问清理、503/拒绝权限、无横向溢出。模拟麦克风不代表实体手机真实孩子音质及评分准确率。
- 部署门禁：PR CI 全部成功 → main CI 成功 → 原服务自动回退部署 → 精确公网 SHA 与 `/english/pronunciation/next-lab` 和音轨访问验证。失败不可声称上线。

## 后续必要工作
真正适合低水平中国学生的短句问答需要一组**独立的短参考答案及其真实 Rust 评分基准**。当前9句 B1 语料较长，当前问答只适合作为可选进阶原型；下一轮扩充受控儿童短句语料、同发音人音轨，再考虑开放语义对话评分，不能把复杂原句缩写后送现有评分 API 冒充正确结果。
