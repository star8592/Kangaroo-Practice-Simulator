# SOC THINK 英语阅读产品线的名称与层级（2026-11-12）

适用范围：仅国内 socthink.cn，不涉及海外 Zoria。当前名称是可迭代的品牌选择，不把 G1–G6 视为官方考试级别或第三方认证。

## 面向用户
- 一级业务：英语学习。
- 二级业务四方向：发音训练（AccentLab）、单词学习（词语星球）、英语阅读（小小阅读星球少儿绘本 + EnglishLeap 文章阅读）、**高阶阅读（AelOS）**。AelOS 不是“综合英语”分类；阅读是其产品主线，其他能力模块作为辅助。
- 儿童产品名：**小小阅读星球**（暂定，可根据家长反馈再优化）。
- 用户可读的分类名称：**少儿英语绘本**、**互动英语故事**；不把术语“分级”作为品牌名字。
- 儿童读者选择入口：小学 1–6 年级，对应 G1–G6。按课程内容循序学习，并不表示官方英语能力等级认证。
- 独立的少儿正式入口：/english/reading/kids/；保留旧 kids-preview -> 正式版的 301 链接。
- 儿童产品和 EnglishLeap 都归属“英语阅读”，不得新增一个独立的第五大栏目。儿童模式从主站领取正式课程导航，不重复开发微信扫码登录或商城支付。
- 免费阅读仅提供绘本、预制语音、触摸互动与本地阅读位置，不声称已有云端学情、正式评分、班级作业或付费权益。
- 品牌与业务数据独立于昵称。未来老师布置作业与统一微信账号通过可信中央身份桥对接，须单独验收。

## 命名取舍
“分级阅读”是描述教学层次的行业术语，适合用于内容说明、SEO 长尾词与课程难度标签，不适合作为反复显示在低龄儿童首页的主品牌。首页用短标题、绘本内容和实际互动反馈替代大段技术说明。
