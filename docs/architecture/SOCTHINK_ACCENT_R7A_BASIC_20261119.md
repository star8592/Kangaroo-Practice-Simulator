# AccentLab R7A — 中国学生基础逐句跟读（保留百分制，增加0.3倍速）

日期：2026-11-19；产品要求追踪：GitHub #380。

## 范围与原则
* **原有基础跟读永久保留**。本轮只优化已上线的 Next.js 逐句候选 `/english/pronunciation/next-lab`；AI 情景对话是未来 R7C 可选模式，不能替换基础训练。
* 针对连一句话都听不全的中国学生：逐词按钮可点读、整句 0.3／0.5／0.7／0.85／1.0／1.15 倍速（默认 0.7）、真实录音评分 0–100 直接展示、下一步只建议一个有服务端证据的重点词。
* 学生首屏隐藏 Rust、ASR、Blob、双轨波形、迁移候选等术语。录音用途与上传说明仍可在明确的 `details` 中打开，绝不以简化界面为由取消告知；教师/原版工作台与详细音频对照继续保留。
* 本轮不修改 Rust 评分协议、题库 ID、作业归属、统一账户/支付。不能根据前端语言文案宣称发音模型准确率改善。

## 0.3× 高品质音轨
* Z890 具备 FFmpeg `rubberband` 变速滤镜；正式生产服务器目前没有 FFmpeg，因此**离线**生成原始九条已批准示范音的 0.3 倍保音高 MP3。
* `public/english/pronunciation/next-lab/audio/slow-03/*.mp3` 为可审计静态资产；`manifest.json` 记录源 URL、源 SHA256、原始与慢速时长、文件大小；九条实测变速比约 3.332–3.333x，总约 1.25MB。
* 学生选 0.3 倍时播放预处理音轨、`playbackRate=1`；选其他倍速时播放原始示范音，并设置 `HTMLAudioElement.preservesPitch=true`。如果当前单句没有预处理音轨、预处理音轨加载失败，则回退到原始示范音的浏览器 0.3 倍速与保音高模式，并明确提示。
* 复现命令：`python3 scripts/build_accent_slow_03.py`（仅批准的开发机执行；依赖 FFmpeg + rubberband + ffprobe；通过已有 GitHub PR 审核）。后续新增或更换音源，应重新生成并审阅；不能凭 ID 假设素材永远不变。
* **尚未完成**跨 Android/微信/不同耳机真人试听的主观音质盲评；时长验证只证明速度处理输出正确，不证明每一个音素在0.3倍下的清晰度。必要时增加“词间停顿”等互补模式。

## 逐词点读与评分
* 单词按钮放大触达、明确显示“每个英文单词都能点”；点击可暂停整句并使用设备 `speechSynthesis` 读当前词，读取学生当前的倍速选项。
* 设备 TTS 的实际语速与声音可能依系统不同，**并未声称其与整句音频是同一发音人**；在“录音、示范音和评分说明”内告知。未来应配合同一发音人的词级音频资源做更统一的音色版本。
* 评分来自原 Rust 评分端有效 0–100 数字，前台显示“本次得分 X / 100 分”。只在服务端返回的错误词确实出现于当前句子时建议“练好这个词”，不推断其具体错在尾音或元音。未返回确切错误词时给出一般性重练提示。不把服务故障或录音不足解释为零分。
* `FocusedWordPractice` 独立单词得分与 A/B 两段真实录音仍可使用；学生可从整句得分页选择“只练一个词”。
* 历史 V3、教师作业入口、课堂记录均保留，不执行删除。
