# SOC THINK 二级页面直达用户任务规则（2026-11-12）

**范围：仅国内主站 socthink.cn；完全不涉及海外 Zoria。**

## 交互规则
- 首页一级栏目，如英语、数学、职业技能、能力测评、考试升学、校内学科，进入二级服务目录。
- 二级页面的每张**具体服务卡片**都是一个大面积可触发的真实入口：标题、图标、文案和卡片空白处，均使用原生 anchor/button 的同一个目标。不得把入口藏在底部小字“进入目录”。
- 只对应一个应用的卡片，直达该应用的 app 路径或实际练习/考试/课程；不再新增单纯的“介绍详情/进入目录”路由阻拦访问。
- 一个能力领域有多个不同目标时，在二级页并列列出不同产品卡片，如英语阅读的“小小阅读星球”和“EnglishLeap”；不得先展示一个“英语阅读”卡片，再要求用户进入三级分类。
- 需要筛选试卷/年级时，可以在**当前页面原地筛选**，但不可通过另一个中转目录来筛选；具体试卷卡片的整块区域触发已有的开卷按钮。
- 一张卡片若有多个**真正不同**的操作（如下载和阅读，研究证据和训练），整卡默认进入主要任务，次要操作保持独立、可点击，不得让覆盖层夺走点击事件。
- 未上线项目不得创建无效的假入口、伪造可用服务。必要的确认、实际考试规则、支付、微信登录是业务流程，不属于应移除的无意义目录层级。
- 所有可点击区域必须具备鼠标、键盘和触屏焦点，使用原生链接/按钮而不是 div onclick，支持浏览器新标签页。
- 本轮只整改主站导航交互与路径，不重建微信、支付、学生数据库或各应用自身的课程逻辑。

## 覆盖面（已修改的主站模板）
英语学习（5个可点产品）、学习与实训、职业模拟、技能实训、能力测评、数字商城、职业指南及试卷卡、校内数学资源列表、数学模拟卷列表；主站一级六大入口本身已是整卡原生 Link、考试目录的 topic 卡本身也是整块 Link，因此不重复包装。

## 验证合同
- 运行 node scripts/test-second-level-entry-contract.mjs
- 所有二级页的整卡点击与实际 URL 由 Chrome 手机/桌面回归验证。
- 不自动下载未经授权的资料、不改变微信用户和订单。
- CI 成功后沿用主站不可变 Next 发布/回退路径。
- 逐页巡检未接入统一二级组件的新增卡片，避免小链接可点、大标题不可点的回归。
