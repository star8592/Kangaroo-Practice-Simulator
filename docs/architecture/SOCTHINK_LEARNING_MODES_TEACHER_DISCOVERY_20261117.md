# SOC THINK：自主学习／教师指导／同伴学习

2026-11-17 用户产品决策：SOC THINK 不要求学习者必须先加入教师班级。自学是默认、长期保留的使用方式；学习者可自愿加入一个或多个老师的班级，在课堂任务里获得指导和反馈，也可保持个人学习。教师在平台内可以选择主动招生，但没有教师许可不能把私有班级自动公开。

## 第一阶段交付

- 首页提供「立即自主学习／找老师·选班级」两条明确路径。
- 个人学习中心以自主学习为入口，同时提供「自己学／跟老师学／跟同学学」三种可并存模式，并展示从已授权学生目录读取的真实班级。
- 教师工作台从自己已授权的班级出发；仍使用统一微信登录、平台角色授权与现有业务服务。
- 新公共「找老师」目录仅收录教师主动公开且邀请码仍然有效的班级。默认私有，老师可以随时撤回；入班仍须微信身份与老师审核。
- 班级公开目录不读取或展示学生姓名、成绩、录音及其他学生数据。原邀请轮换与停用保持有效。

## 付费指导的后续闭环

平台可以同时有免费自学、个人高级专项权益、可选的老师付费指导、班级共同任务。与可汗学院免费公共教育服务不同，SOC THINK 的导师指导服务由本平台设计运营，不能引用可汗学院的收费或组织政策。

付费课程必须在统一平台产品目录、正式定价、支付及退款、授课人合规资质、服务履约和确认权益后才可公开标价销售。禁止老师在公共招生页私自放付款二维码，也不能将「申请入班」假称为已购买。席位与课程权益要经过服务端鉴权和实际订单入账。

老师看到的只应是授权班级的课堂成果；个人自学历史不得因入班自动全部对教师开放。未成年人参与小组讨论、排行榜、外部社交分享，需要独立的隐私和监护人规则。

## 现实边界

当前第一阶段提供公开班级发现、教师选择性发布及真实班级入班，不提供不存在的跨学科统一任务汇总、不声称已支持付费班成交和老师自动分账，也不冒充已上线的社交小组聊天。后续单独验收统一 SKU、支付购买、席位、老师指导协议和小组互动。
