# AccentLab R7B｜基础跟读 + 单词专项两个独立学生入口

日期：2026-11-19。基于已正式发布的 R7A（0.3×慢速、百分制与逐词点读），本轮仅改变 **Next.js 学生端** `/english/pronunciation/next-lab` 的学习模式入口。

## 学生操作
- 默认进入原来的「基础跟读」：逐句听、点词试听、整句录音、100分真实评分、根据有证据的词提示复练。现有界面及评分协议保持。
- 旁边新增「单词专项」：不要求先完成整句评分，直接选择当前句子里的任意一个词；听示范、录下这个词、等待原有 Rust 单词评分，以 **真实 0–100 分**反馈，支持 R5 最近两次真录音 A/B 本地回放。
- 两种模式自由切换，不创建新账号、班级、题库、支付体系。切换时销毁单词组件的临时录音和权限回调；录音/评分期间禁用切换，以免误操作；换句重新初始化待练单词。
- 单词专项支持 0.3 / 0.5 / 0.7 / 0.85 / 1.0 / 1.15 速度，但 Web Speech 设备 TTS 的实际音质受浏览器限制，不能将其伪称为统一标准发音人或保真 0.3 音轨。R7A 的 Rubber Band 超慢速**整句**音轨不受改动。
- 暂无可用受限 AI 对话实现，本轮不摆空入口、不虚构评分或作业保存。
- 学生界面不暴露技术细节，原有录音隐私说明保留；教师课堂与正式旧 V3 不变。

## 验收
`tests/e2e/native-direct-word-r7b.spec.ts` 应通过桌面/手机 Playwright 两个实际浏览器分片。第一条验证未完成整句评分即可单词录音、单词 score-word 接口真实受控返回，并能切回基础跟读；第二条验证切句重置单词状态且无假评分/横向滚动。现有 R5、R6、R7A 回归不得失败。所有测试使用模拟麦克风，不能代表真人儿童口音或实体手机认证。

合并后仍需主线 CI-green → 原自动回退部署器 → 公网 SHA + 关键路径查询。不得以PR合并代替已上线。
