## 主站负责的可执行工作单元

- `/assessments/english-speaking` 管理对外考试目录、地区/年份/正式或研究候选标识，保持“考试中心归考试、发音练习归AccentLab”。
- `/my/learning` 和 `/workspace` 负责本人学习进度、已批准班级及教师作业；复用现有主站单一微信会话和AccentLab课堂RLS，学生数据不得跨班、跨用户读写。
- Next原生候选 `/english/pronunciation/next-lab` 的R5单词两遍A/B、R6整句麦克风异步保护 **已在主站PR #375/#376合并**，不要再次创建并行且相互冲突的声学诊断实现。是否完成正式部署须以线上回执另证。
- 统一账本 `/api/platform/billing/me` 对 pronunciation 当前仍为not-onboarded；需要建立 **产品专属** 10次免费AI评测、¥19.90/30天每天30次AI评测权益、交易回调与真实服务端原子扣次。AccentLab R52 #137 **只完成草稿会员页**，不能宣传已可购买。
- 真正需要新增的是 **exam attempt→可证明的薄弱项→专项练习→不同材料复测** 的跨模块任务关联。现有考试报告仅有“根据反馈专项复练”通用链接，并非已经实现有证据的个性化推荐。
- 武汉2027 W1—W5是候选训练，不是正式机考最终大纲。正式规则核对、变更历史和模拟评分来源必须可追溯；高考不得借用中考配置冒充已实现。

## 面向学生的唯一行为闭环

```text
地区考试/听说能力摸底
 → 可核验成绩覆盖：听力选择对错、有效朗读参考分、开放题待人工复核
 → 最重要的1—2条练习建议（带证据等级）
 → 已有发音/听辨/录音A-B/重练模块
 → 新材料复测
 → 学生本人和授权教师的学习记录
```

**实施顺序**：先做考后按题型进入准确专项训练，再在统一登录的授权条件下保存结果；儿童专用音素提示必须通过教师人工真值验证后才作为确定性诊断。无证据时可用原声比较，不生成错误词或官方分。完整发音研究与发布验收清单见唯一总纲。
