## 1. 产品战略（决策版）

**主品牌：SOC THINK；定位：全球数学竞赛与成长平台**  
**英文：SOC THINK — Global Math Competition & Growth Platform**

定位不由单个产品入口决定。核心承诺：帮助学生找到适合自己的数学练习与全球竞赛，并依据可验证的学习和参赛记录判断下一步。

四个业务中心：
1. **数学训练**（频次）：从小学计算到初高中代数/函数/概率统计，诊断、专项训练、错题、个性化建议。
2. **竞赛模拟**（专业测评）：历史题、不同赛制、计时、答题卡、规则准确评分、完整题干及选项双语朗读、评分与复盘。
3. **全球赛事管家**（差异化）：公平呈现中国和国际赛事；基于地区、学段、实际资格、截止日期和兴趣筛选；官方来源、核验时间、收藏和个人备赛流程。
4. **数学成长档案**（留存与信任）：长期训练记录、真实成长曲线、赛事跟进、家长视图；“站内模拟荣誉”与“赛事官方获奖”须明确分开。

**优先价值**：完成任务 > 品牌修饰；可靠准确 > 堆砌竞赛数量；用户自主选择 > 强迫线性路线；清晰披露 > 未验证的时间/奖项/授权。

## 2. 多方研究：吸收边界

| 来源与证据 | 优秀做法 | 取舍和反面边界 |
|---|---|---|
| Khan Academy [Mastery](https://support.khanacademy.org/hc/en-us/articles/360007253831-Using-self-paced-practice-and-Mastery-in-the-classroom) | 跨课程掌握度、教师可追踪练习 | 不在样本稀疏时伪造精细能力评分 |
| Brilliant [FAQ](https://brilliant.org/faq/) | 交互式探究、逐步提示与即时反馈 | 不复制其课程结构、不把 AI 提示变成答案泄露 |
| Art of Problem Solving [Alcumus](https://artofproblemsolving.com/alcumus) | 挑战题、适应性、专题和成就 | 成就只能辅助激励，不喧宾夺主 |
| Waterloo CEMC [Contests](https://cemc.uwaterloo.ca/contests) | 赛事年级、赛历、地区差异、截止日期与官方资源 | 全球活动≠中国赛区可报名，必须按 edition+region 核实 |
| UKMT [Competitions](https://ukmt.org.uk/competitions) | 赛事系列/年龄分层/官方报名规则 | 不能把“本站在线模考”描述成“官方在线竞赛” |
| AMT [Competitions](https://amt.edu.au/competitions) | 报名资格、承办主体、训练资源与正式比赛区分 | 不宣称本平台有官方合作或授权，除非有证据 |
| 教育部 [2025–2028 全国性竞赛名单](https://www.moe.gov.cn/srcsite/A29/202510/t20251029_1418393.html) | 中国赛事监管与政策适用边界 | 历史竞赛名称≠入列白名单；竞赛结果不可宣传为招生加分 |
| W3C [WCAG 2.2](https://www.w3.org/WAI/standards-guidelines/wcag/new-in-22/) | 清晰交互、键盘无障碍、触控可及 | 不使用只有小图标/无标签的关键操作 |

调研结论：不是创造“更多卡片”，而是构建 **“发现—诊断—训练—模拟—参赛准备—复盘—成长”** 可循环的单一用户旅程。外部平台的营收/留存结论尚需 SOC THINK 自身数据验证，不预设转化数字为事实。

## 3. 用户细分与端到端 Jobs To Be Done

| 角色/阶段 | Job | 完成标准 |
|---|---|---|
| 首次游客 | 立刻了解能做什么、完成一次有效练习 | 不登录进入允许的训练，得基础结果，明确下次入口 |
| 学生（日常） | 快速进行年级适配训练 | 选择年级/专题/模式，答题和反馈完整，不被虚假权限阻断 |
| 学生（备赛） | 找到一套正确赛制的考试并完成 | 选赛事/年级/真题，提交，获得符合赛制的分数和错题 |
| 家长 | 找到孩子当下值得参加的赛事 | 地区学段筛选，明确已核验/待核验资格与报名时间，收藏提醒 |
| 家长（成长） | 判断孩子是否进步 | 具有数据覆盖说明的趋势、错题策略、可复用计划 |
| 教师（后续） | 为多人布置并检查训练 | 班级组织、隐私隔离及批量分析（不进入 P1 上线范围） |

**有意降低摩擦**：开放内容不能以注册为唯一入口；跨设备同步、保存长期报告和高级权益在恰当时点提示绑定身份。微信静默登录也不得造成隐式越权；全卷模考权限以服务端策略为准，客户端文案必须一致。

## 4. 统一信息架构

Web:
- 首页 `/`：即时行动（开始计算/开始模考/探索赛事），当期赛事摘要、个性化最近进度（登录且有数据时）、可验证的产品能力。
- **计算训练** `/arithmetic`：按学段/知识点/时长/难度进入，完整数学输入、打印和诊断。
- **竞赛模拟** `/competitions`：现有试卷聚合入口保留；未来兼容 `/exams` 别名须先测试链接。
- **全球赛事** `/events`：使用 `WORLD_COMPETITIONS` 公共目录，不需要学生会话；可按地区/学段搜索，进入主办方与可用模拟入口；后续个人日历/关注。
- **成长档案** `/student`（学生）与 `/parent`（家长）；游客见明确使用说明，不能在首页首屏伪装已存在数据。
- 错题复盘 `/review` 是训练/成长二级功能；验证 `/verification` 是可信度工具页；会员权益按实际权限公布。
- 旧 URL、搜索索引与分享卡片保留可访问性；新链接必须有自动化校验。

小程序：
- 长期 5 Tab：**首页/计算/模考/赛事/我的**。现有 4 Tab 暂时不盲改成 5 Tab；`events` 当前是 `navigateTo` 子页，若提升为 Tab 必须同步重写带参数跳转机制，以短期 storage intent + `useDidShow` 消费后删除，测试所有跳转路径。
- 首屏在一个设备视野中出现计算、模考、赛事三个实际可点操作；“我的”集中学生/家长/权益/成长。
- 模考和赛事不在一个无限滚动列表里长期混排；在渐进改造期间分别提供直接指向真正页面的明确入口。
- Web/小程序名称、实体 ID、状态字段、访问规则、题目渲染和记录保持语义一致，不追求页面像素完全相同。

### 首页内容优先级

1. 品牌一句话价值：**练好数学，探索世界数学竞赛**。
2. 三个真实 CTA：开始计算训练／参加竞赛模拟／探索全球赛事（点击即启动任务）。
3. 当期/关注赛事：明确校验时间、没有官方日期时不展示倒计时。
4. 学生当前进度：只有真实数据时显示指标；新用户给“开始一次测评”。
5. 适合我的下一步：理由和证据透明，允许跳过推荐自由选择。
6. 关于平台可信度、订阅权益和更丰富的内容（放首屏以下）。

## 5. 数据与可靠性架构（源头复用）

| 概念 | 关键字段/语义 | 约束 |
|---|---|---|
| Competition（赛事系列） | eventId、region、nameZh/en、organizer、sourceUrl、referenceStages | 一套全球目录，无“中国次级专区”；来源不等于授权 |
| Edition（届次） | year、region、host、eligibility、mode、registrationWindow、examTime、verifiedAt、sourceEvidence | **未知字段必须 null**；不允许猜测当前届截止日期 |
| ExamProfile（考试赛制） | questions、duration、scoringPolicy、language、sections、maxScore | 真题/样题/站内模拟严格标注，规则版本化 |
| Attempt（作答） | student/session owner、answers、events、snapshot、idempotencyKey、submittedAt | 答案草稿归属验证、重复提交无二次扣费/计分 |
| Follow/Reminder（关注提醒） | eventId、editionId、student/household、state、channel、consent | 关注≠报名；订阅消息是否真实开通须提示 |
| Report（结果） | coverage、accuracy、questionStats、observations、confidence | 无充足样本不得假称精细能力结论 |
| Honor（荣誉） | type: simulation / verified_official、issuer、evidence、date | 模拟奖状显著标注“非官方比赛成绩” |
| Entitlement（权益） | scope、expiresAt、revokedAt、purchaseSource | **服务端**校验与退款撤权；匿名会话不可越权 |

复用已存在的 `WORLD_COMPETITIONS`、companion 和考试引擎；新增字段采用 additive migration，避免未经评审的 schema 重置。发布、备份、回滚与版本签名复用既有工程体系。

## 6. 视觉语言、可用性与无障碍

沿用 `docs/UI_DESIGN_SYSTEM.md` 的页面宽度、间距、响应式分界和共享组件。重新规划的是导航与信息密度，不追求为了视觉震撼而延迟可用性。

- 主页主操作有足够对比度和明确的动词；卡片全部有真实目的地和失败退路。
- 初高中数学符号输出、输入、复杂分式/根式、移动输入板与回显必须成组验收。
- 模考独立工作台：规则、时间、答题卡、上一题/下一题、标记、语音语言、自动保存、交卷确认和成绩恢复。
- 中英语音读题包含题干与所有选项，并与当前题/语言一致；需尊重静音、暂停、重复。
- 符合 WCAG 2.2 AA 的适用要求（对比度/键盘/焦点/触控/表单语义）；避免按钮小到无法点击。
- 空态说明下一步而非显示“0分”或“未有成绩”的悬空图表。
- 对于未拥有商业使用权的题目、第三方标识、官方资料：采用来源链接/适法授权或仅使用可用资源，不能忽视版权。

## 9. 工程验收与度量

**功能 E2E**：入口→筛选→试题/赛事详情→退出/返回；匿名计算 10 道并得分、正式模考存草稿→交卷→复盘；中英题干加全部选项朗读；断网/重新进入恢复；家长绑定/切换孩子；深度报告无权限时无法通过直接 URL 绕过；支付/退款幂等。

**质量门**：`npm run test:brand`、`npm run test:world-companions`、`npm run test:china-companions`、`npm run test:miniapp-parity`、`npm run test:exam-access`、`npm run test:e2e:smoke`、`npm run verify:miniapp` 中适用的检查；如已有失败必须留测试输出/归因，不得宣称全部通过。每个实现 PR 对照其影响范围另增测试。

**观察指标**：训练/模考/赛事入口点击成功率、首个有效答题时间、游客首次任务完成率、模考完成率、赛事关注/提醒成功率、家长7/30日留存、跨端身份错误数、公式错误率、点击死链数。首次发布采集基线后确定 SLO；建议关键任务 0 死链为封板硬门。

**上线凭证**：PR/commit、CI、staging URL、移动真机、真实 Web 访问、发布版本号、日志、回滚演练结果；未有上述证据，不应宣称上线。

## 10. 反对意见与风险应答

1. **过宽**：四业务是否使产品失焦？解决：每个用户旅程只优先展示 1–3 个动作，不一次暴露全部页面。
2. **赛事数据质量**：加更多国内赛事可能造成不实宣传。解决：官方/当届/赛区逐项核验，目录与资格分层。
3. **移动改版回归**：Events 变 Tab 会导致 navigateTo 失败。解决：待所有跳转处迁移且无参数深链替代测试通过，再切换配置。
4. **用户权限冲突**：开放训练与登录后完整模考可能同时存在。解决：按动作/资源类型从后端返回具体资格，UI 统一解释。
5. **商业转换过早**：用户还不能顺利训练就上付费。解决：可执行关键任务先于商用权益。
6. **多分支相互污染**：现有工作树非干净。解决：新工作分支、单目的 PR、CI/审查/灰度与回滚；不要直接覆盖既有版本。
