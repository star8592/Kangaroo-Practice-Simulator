## Student gate

A source-language question is exposed only when:

- Chinese and English text both exist;
- answer/source extraction is verified;
- translation review is complete;
- visual review is complete;
- source-language-dependent labels are removed or localized;
- required student assets exist.

Full-score and blank-paper scoring regression is run for promoted exam bundles.
