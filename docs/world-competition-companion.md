# 世界数学赛事管家 · World Math Competition Companion

## 产品原则（2026-10-09）

核心设计不再是“中国专区 + 国际专区”，而是一个**全球数学赛事目录**。中国赛事与其他地区赛事同级展示；地区只是属性、筛选维度，不能决定赛事权重。国家、语言、所属组织、考试形式、参赛赛区、届次分别建模，不能把总部所在国等同于学生报名地区。

**唯一流程**：发现赛事 → 资格/赛区核验 → 报名准备 → 真题训练/模拟 → 线上设备调试或线下赴考 → 成绩/证书归档。任何赛事均可建立准备清单，训练资源未入库不冒充已入库试卷。

## 第一阶段落地

- 10项同级赛事：袋鼠、华杯赛、澳洲 AMC、走美杯、美国 AMC、希望杯、加拿大 CEMC、全国中学生数学奥林匹克、英国 UKMT、中国女子数学奥林匹克。
- 网站首页和 Web 全球目录统一展示10项赛事：首页卡片通过 event 参数直达目标赛事；赛事目录在模拟试卷库之前，列表采用交错展示，不设“中国/外国”主从层级。地区筛选：全部、中国、美国、澳大利亚、加拿大、英国、全球性。
- 小程序“竞赛实战”和“赛事管家”使用同一赛事目录 API，赛事详情与训练分开，且真实点击跳转至同一管家。
- 复用原有学生任务完成进度 API；中国历史赛事与海外赛事准备清单均禁止无依据日期/报名倒计时；澳洲 AMC 2026 已核验的特定中国赛区流程继续保留，到期切换为普通备赛模板。
- 向后兼容旧的中国赛事 API，避免破坏历史客户端。

## 后续工程化

- 引入独立的 CompetitionEdition / RegionalSession / Enrollment / Milestone 届次层，不应在赛事主档中直接存报名日期；核验来源具有 verifiedAt、validThrough、sourceScope 与实际适用赛区。
- 补充按学段、居住地区、兴趣筛选与关注；一名学生同时关注多赛事时，显示跨赛事最重要的三件事，不推送多余通知。
- 保持统一权利与隐私隔离；赛事运营主体、渠道和奖项真实性不可凭历史名称推断。

## 测试门禁

- npm run test:world-companions 检验同级目录、稳定 ID、没有伪造日期、可识别的进度任务以及特定赛事期限。
- Web 桌面/手机 E2E 验证地区筛选、两个不同国家的完整任务时间线、来源和游客权限。
- 小程序真实编译/同源 API parity 必须通过；微信正式版上传仍需 SHA 对应的开发工具及真机 QA 凭据。
