# SOC THINK 职业模拟笔试与题库规范（2026-11-01）

## 现行唯一考试产品

**正式岗位模拟笔试**：首批采购与供应商管理、商品运营与增长分析、工业质量与FMEA，各24题、45分钟、100分，共72道原创客观题。全部采用独立题库版本、考点和答案解析。正式入场前展示职位范围、题量、时长、原创性质、试卷版本和入场规则；用户确认后领取签名入场令牌，45分钟计时。考场含固定计时器、答题卡、标记待检查、翻题、交卷前检查、到时自动交卷和服务端固定规则判分。微信账号已验证后记录独立成绩，未登录仍可免费答题。

**明确废弃**：早期三套各6题的“岗位实操/热身”版本，既不符合岗位笔试的完整性，也损害考试仪式感。2026-11-01确认全部移除，不保留热身入口、不作为售卖产品、不保留其公开题目定义、答题组件、评分代码、路由或相关自动化测试。旧 `/career/practice/[id]`、`/api/career/practice/[id]/grade` 等接口必须为404，不允许再发布。正式考试入口统一 `/career/exams/[id]`，申请入场 `/api/career/exam/[id]/session`，交卷 `/api/career/exam/[id]/grade`，微信成绩 `/api/career/exam/history`。

出于用户数据安全，发布流程**不批量删除曾经产生的个人成绩快照**；但这些旧6题记录不被新考试目录、账号考试历史或新成绩接口展示和引用。本次删除的是旧版产品及其运行代码，而非进行有损的数据删除。

## 题量与依据

本轮交叉研究：招聘笔试题量无跨行业统一平均值；部分大型校招在线笔试约60–120分钟，技术岗有15道客观题+3道编程、4道编程题等，行业和招聘场次差异大。24题/45分钟是本站**第一版模拟规格**，不是某家企业官方题量、历年平均或招聘保障。应按公司、岗位、年份与题型分别统计有证据的结构，不能把一类笔试推广到270个岗位。

参考研究源记录在 `data/career/formal_exam_sources_20261101.json`。包括牛客面经、知乎质量及供应链话题、Aon和SHL测评机构公开说明等。平台真实题目要区分：
- 企业官方公开样题：清楚列出发布单位、链接、发布时间、版本及授权范围。
- 考生回忆版：标明“个人回忆，非官方核证”、自述考试时间（若有）、原帖发布时间、采集日期，不在缺少版权授权时复制完整原题。
- 第三方整理/改编版：标明“第三方整理/改编”，不可冒充企业原题；明确版权使用条件。
- SOCTHINK原创模拟题：日期为**原创编写日期**而非企业实际考试日期，必要时另列参考考点的采集日期和外部出处。不能把参考考点页面写成这道原创题的原题出处。

## 题库模型

原始版题库存于：
- `data/career/formal_exam_procurement_20261101.json`
- `data/career/formal_exam_operations_20261101.json`
- `data/career/formal_exam_quality_20261101.json`

每题有独立ID、题型、技能点、题干、选项、标准答案、明确解析、4或5分、编写日、来源分类及考点参考ID。服务端加载原卷和答案，公开页面只序列化试卷题面与可展示的来源元数据；严禁把 correct 或 explanation 发给客户端用于交卷前渲染。

所有新题从来源采集开始，必须经过来源去重与版权审查、题干原创改写或授权使用、知识点审题、答案交叉验算、专业审核、版本发布和浏览器交卷验收。来源不能核实就保留待核，不可自称已抓取“企业真题”。

**更新机制**：新题增量入库，不覆盖旧成绩所指的历史卷和评分依据；题库跟踪最后来源复核日期与新题入库日。若未采到真实新资料，后台不得假装持续更新。未来有实时抓取权限后按源站机器人/授权范围建立变更采集、重复指纹和失败原因记录。
