# ADR-001 · SOCTHINK 超级考试与综合测评平台

**2026-10-30 · 原仓库 `star8592/Kangaroo-Practice-Simulator` · 主域名 `socthink.cn`。**

## 战略定位
从“G1–G12 数学与国际竞赛系统”升级为**考试、测评、真实技能验证和可解释解题平台**。数学是第一个已成熟的领域，不再把每个学科当作独立站点。核心闭环：用户寻找真实任务→免费试做→在线考试/仿真实操→有来源、有证据的评分及多媒体解析→针对性训练与复测→自愿按卷、会员或机构付费。可打印卷只是同一试卷的交付方式，不是额外题库。

七个业务领域统一 Catalog：
- `school`：K12 学业能力、各科考试、练习册/错题与进步诊断。**数学已可用**。
- `math-competition`：澳 AMC、MAA AMC、袋鼠、CEMC 等国际数学与赛事。**既有竞赛可用**。
- `language`：TOEFL、IELTS、SAT 与英语听说读写。**待按许可与评分能力开通**。
- `university`：大学学科、研究生升学、专业考试与学术技能。**待验证需求**。
- `career`：大学生就业，Python/SQL/数据分析/AI 实操、岗位模拟面试。**第二条优先做通的产品线**。
- `professional`：职业资格、公职、法律及各类岗位执业能力。**待验证资源**。
- `interest`：职业兴趣、能力偏好、非临床心理问卷。**必须标明量表信效度与边界**。

**不把“目录里有一类”当成“已经有产品”。** 未上线的业务类别不得创建假考试、错误链接或伪造报名与付款入口。

## 跨业务唯一平台底座

```
PC Web + Mobile Web + 微信小程序 + 未来机构/企业控制台
          ↓统一品牌、内容检索与可实际点击的服务入口
现有身份和家长/学生关联 ── 权益、订单、配额、退款（沿用原账本）
          ↓
      Assessment Core（模块化单体）
  Catalog / Item Bank / Blueprint / Attempt / Grade
  Rubric / Skill Profile / Report / Retest / Delivery
          ↓
  Provenance & Rights / OCR Pipeline / AI Solution Media
  Sandbox Task Runner / Quality Review / Analytics & Unit Economics
          ↓
  数据库 + 原始资料对象存储 + 异步作业队列
```

数据主模型必须包括：来源文件的 URL/作者/版权/抓取时间/原件哈希/许可范围；题目版本、题干及公式图像、答案/rubric/知识点、可发布状态；考试蓝图（数量、计时、权重、组卷策略）；不可改写的提交快照和评分证据；多种媒体答案按题目/答案版本绑定；跨场景但不可乱比的能力画像；真实订单与额度；可追溯纠错记录。前台门户和微信小程序只能读同一份有真实可用性标志的注册表。

**考试类型**不仅是选择题：单选、多选、数字/符号、开放问答、听力与口语、作文、代码测试、SQL 与文件实操、容器沙箱、互动面试和科学量表。各自有适用的评分适配器，但提交、授权、重试、报告与复测协议共用。自动 AI 打分需要 rubric、置信度与复核；不能把模糊文本当成确定性正确答案。

### 内容工厂（真正长期竞争力）
发现合法来源→PDF/图片/OCR→数学与图片结构化→题目/答案匹配→去重→来源和商业分发权确认→确定性验算/人工抽样→多语言翻译→生成分步解析/矢量图/动画/短视频→可审计发布→搜索收录→反馈和修订。每个阶段有数量和失败原因统计，不能在下游暗中再次筛掉已合格内容；优先缓存、批量运行、去重复算。未经许可的版权资料仅作有权范围内的私人辅导，不可因“网上可搜索到”就公开转售。

### 技术策略
- 保留现有 Next.js 前端及已验收的数学提交/判分/登录/微信/支付路径；未来稳定核心以 **Rust 模块化单体**扩展，不另起数套服务。先数据协议和结果一致性测试，再逐模块替换现有后端；禁止为了语言转换推倒可用考试。
- 现有 `competition-agent`、`ops/data`、`student-analytics`、AI 解析管线作为适配器，不复制并存第二个“学生画像”“账本”或“解题平台”。
- 生产采用已有 CI→单一自动发布器→库存不减→回退→公网 SHA 回执；原数学目录的未提交朗读等工作不能覆盖或强制重置。
- 公开 SEO 只收录合法、有实际可用内容的真题解读、原创习题、能力指南与视频解析，不生产数万个零价值薄页。统一 URL、canonical、内容版本、更新时间和结构化数据。

## 客户与商业，不再以闲鱼为核心
- B2C：免费做题和基础结果、单卷/题组低价、增量报告与会员。此前讨论的 **¥2.9–9.9/卷、¥19.9/月只是待 A/B 测试定价，不代表线上已验证收款**。
- 大学生与求职者：技能基准测评、仿真实操、岗位报告与模拟面试包，区别于廉价简历润色/批量投递。
- B2B 教师/机构：老师布卷、班级诊断和授权题库，按席位/使用量。
- B2B 企业：与真实岗位一致的评估、代码与实操沙箱，按测评使用量；不能贩售学生个人数据。
- 要严控每次 AI 生成、视频、沙箱和支付通道费用；会员要有额度，不能用不限量模型成本换低价。

## 开发排序与明确验收
**P0 平台骨架（本 PR）**：统一七域 Catalog、真实功能状态、总服务目录、首页/导航可达；数学训练和竞赛仍实际可做，未上线域不可点击虚假考试。所有旧路由继续有效。

**P1 核心统一**：数学与国际竞赛两种现有产品接统一 Blueprint/Attempt/Scoring/Report/Entitlement 规范和模型适配器，不改评分结果；新旧答案双跑校验。

**P2 做出第二条真实产品线**：以 SQL/数据清洗/AI 应用岗位为试点，任务→隔离实操→真实运行评分→报告→复测，至少一个用户能真实做完的完整闭环。随后岗位模拟面试，不以简历代投当核心业务。

**P3 自动生产**：来源/许可/题库/解析图视频/发布/SEO 自动化流水线，质量和版权审查集中在统一门禁；真实单位成本统计。

**P4 收入验证**：复用已有微信登录、网站支付/权益，真实试购→验签→权益→消费→退款/对账，随后小额单卷/月会员实验。不要把已有支付代码等同于真实交易验收。

**P5 扩展**：英语、大学升学、职业资格、兴趣与机构/企业产品，由真实订单、完考率、复测与毛贡献率决定优先级，而非每类建一个空网站。

统一经营指标：来源候选→验证合法→正确可分发→上线题目数；浏览→开始→完成→看解析→复测→付费→退款/续费；每领域人均 GPU/OCR/LLM/沙箱成本、纠错率和单位毛贡献。严禁以 OCR 候选量、网页数、模型生成量代替有效商品或收入。

## 对外竞争形态参考
TestGorilla 把职业技能测试、AI 面试、岗位仿真与 B2B 支付整合为同一产品（https://www.testgorilla.com/assessments/）。HackerRank 的岗位评估以可执行代码和岗位测评为单位（https://support.hackerrank.com/articles/9999244916-question-types-in-hackerrank-interviews）。这些说明职业“考实际能力”可以是独立业务线，**不表示其营销数字已核实或可以复制其收入**。

最终原则：**建设一个可长出很多行业测评的底座，不是继续修饰当前数学考试站。** 客户意见处理台只是质量保证模块，不再挤占平台架构主计划。
