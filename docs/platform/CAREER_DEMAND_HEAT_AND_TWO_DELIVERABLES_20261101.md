# SOC THINK 职业需求热度与两类可交付产品：2026-11-01

## 用户问题与本轮实际改造

原职业中心把16类岗位/公开来源排在页面前部，却缺乏“需求热不热”和“我现在能买/用什么”的答案。正式交互主线应为：

**有出处的就业/招聘指标 → 资料教程（数字商品） → 在线考试服务（数字服务） → 按岗位浏览具体证据及内容进度。**

两个产品类型并列，而不是把教程伪装成试卷、把考试服务伪装成下载文件。所有交付都由确实存在的题目/原文内容支持，未开发的内容不可显示为“可购买”。

页面引用的是注明日期的媒体转述，保留完整来源链接；未获取外部平台许可的实时岗位规模API。其余12类岗位**显示“暂无可比数据”**，并不标成“冷门”或热度为0分。优先继续采集可核验且同口径的权威岗位数据后再扩展。

### 2. 本站自己的岗位采集证据，单独展示

2026-11-01的人工选定非随机企业样本包括9家样本雇主、36条公开来源信号、17条职位级描述，涵盖16个岗位领域。每个领域显示：
- 本库共收录多少条样本，多少份职位级描述，来自多少家样本企业；
- 仅作为**本站研究覆盖度**的相对条形图，分母是本站16类中的最大样本量；
- 企业原始链接折叠在可展开的“招聘证据”中，保留采集时间和职位级/岗位类别级标识。

这些不是招聘公司总数，更不是当前有效岗位数。岗位类别页面不构成“职位空缺已经得到证实”，不得生成虚假热度分或假考试SKU。

## 二、产品二分法：数字商品与数字服务

### A. 数字商品：真正有内容可交付的原创教程

目录 `/career#digital-materials`、独立阅读页 `/career/guides/[id]`、下载接口 `/career/guides/[id]/download`：

1. `supplier-decision-handbook`：采购供应商选择，4个完整章节、合格率反推、到货成本、预算与产能风险、练习和参考答案。
2. `retail-campaign-roi-handbook`：商品运营，4个章节，退款后收入、净贡献、广告ROI的比较、预算约束、练习答案。
3. `manufacturing-fmea-handbook`：工业质量，4个章节，失效模式、S/O/D、RPN计算、控制计划及局限性、练习答案。

每份都由本站原创，真实可下载完整Markdown文档，阅读页面还提供浏览器原生**打印/另存为PDF**的可执行按钮。Markdown下载使用附件响应头、中文文件名和nosniff，不通过未授权外部网盘“占位”。**本轮全部为免费资料，不属于已完成收费交付的商业SKU。**

不能把课程指南中的虚构计算当成雇主官方材料或执业证书。文本解释尤其要注明ROI的简化模型与AIAG-VDA FMEA行动优先级不同于RPN乘积排序。

### B. 数字服务：真正运行的考试系统

目录 `/career#digital-services`，复用此前公网验证的：
- `supplier-selection-001` 采购6题/100分
- `campaign-performance-001` 商品运营6题/100分
- `manufacturing-quality-001` 工业质量6题/100分

每套真实题目支持用户作答、服务端评分、逐题解析、重新挑战；已验证微信账号复用现有私有成绩历史。其余尚未生成可测试题库的“商品候选”仅在证据详细视图显示“尚在规划”，无报价、付款或“已上架”按钮。

### 商业计划与当前状态必须分开

目标商业类型：
- **数字商品**：教程、专题复习资料包、题集、练习卷、附解析的可下载文档。
- **数字服务**：在线模拟考试、训练服务、自动评分与深度能力报告、未来的复练订阅。

当前3个免费完整教程 + 3个免费在线实操只用于证明用户能够完整拿到内容、使用服务。真实收费仍需使用**当前微信单账号 + PostgreSQL账本 + 已核验商户支付**；事先完成内容权益注册、SKU绑定、订单签名通知、下载/报告授权及验收，不另建收费服务。若 `billing-ledger` 尚不接受职业报告内容种类，先扩展正规的产品注册和权益协议，不得伪造旧类别。

## 四、下一轮应增加的后台指标（暂不冒充已实现）

需要从有权获取的招聘数据源定期取得同口径职位总量、采集时间、去重雇主和招聘地点，保留版本和复查原始URL；与站内访问、教程点击/下载、考试开始/完成、免费→付费转化指标**分开统计**。数据质量异常时隐藏数字，而不是使用固定假热度。

未来可展示“外部岗位需求热度”和“本站学习关注热度”两条独立曲线；目前没有足够规模化的求职指标或站内埋点支持这种曲线，故本轮没有虚构它们。
