## 一、范围：最近三个考试年度

默认只搜集和结构化**2024、2025、2026**考试年度；跨年度考试记录官方season + 实际举办日期。2027新版规则经主办方发布时可先创建2027当前赛制，但2024原卷继续按2024当年规则评分。超出三年仅在需求与合法来源明确时例外。按**主办方、考试系列、赛区、年度、年级/级别、答题介质**建立最小区分，不按「国家」猜规则，也不把美国AMC和澳洲AMC混淆。

资料至少分为：官方公开真题、官方公开样题、用户拥有但尚无转载许可的文档、独立原创仿真题；每项都要独立记录实际内容年份、出处、语言、答案和解析完整度、SHA256、访问/许可条款。**网页可读、下载成功、OCR提取成功不等于可收费或可在本站重发布。**

## 四、仿真考试的**版本化规则合同**

每份试卷绑定不可变`formatVersion`，规则最低字段：

`familyId / organizerId / regionId / edition / gradeBand / formatVersion / sourceUrls / verifiedAt / effectiveFrom / timeLimit / questionBlocks / answerTypes / scoreCorrect / scoreWrong / scoreBlank / startingScore / navigation / submission / calculator / breaks / languageAndAudio / adaptiveRouting / scoreScale / rightsId`。

共用唯一考试会话、答题自动保存、倒计时、跳题、标记、交卷/超时、考试记录和报告；**不同赛事只用独立策略配置/必要策略函数**，例如SASMO负分和起始分、AMC10/12空题加分、AMT整数填答、托福/SAT多阶段、自定义音频与录音题、主观评分。

每个版本验收全对、全错、全空、混合、超时、重复提交、断网恢复、不同年级和赛区、手机与小程序输入；逐个对照官方规则。官方隐藏自适应评分算法不可仿造时，页面明确标识「近似诊断，非官方等值评分」。低年级语音读题可作训练辅助，但不应误称为真实考场允许。

## 五、内容生产双线

**A 资料**：官方网站/官方公开卷与样题/本地文档 → 来源与考试年份核验 → 授权状态 → 原始SHA256与元数据入私有归档 → 数字原生PDF/OOXML优先提取、冲突再OCR → 图形、数学符号、选项、答案、解析二次检查 → 权利确认 → 现有唯一题库审核与原子发布。

**B 考试**：当届官方规则 → 年级赛区差异 → 规则快照 → 典型卷装配 → 评分真值表与交卷异常用例 → Web/微信真实作答 → 发布回执。未补全原卷或没有使用权时只提供经授权的样题/原创练习；不能标识「官方完整真题模拟」。

**资料商业化重大风险**：现有来源登记`siteMode=noncommercial-free`且登记项`commercialUse=false`，与现在收费网站规划有冲突。**禁止直接改true绕过版权**。CEMC官方条款规定CC BY-NC 4.0且不得对历年试题练习资源收费；其他主办方亦单独核查授权。收费的原创服务与不得商用的原题资料分离，任何原题公开/商售必须有可证明权利。

## 六、实施顺序与持续更新

**P0 资料存量**：对2024–26按`赛事×年份×赛区×年级`生成**实际卷数/答案/解析/来源/版权/规则已核实/可发布状态**矩阵，排除日期混淆，统计缺口，按需求排序。

**P1 综合考试扩充**：托福2026新版、雅思机考、SAT数字化、国内各类升学与职业考试分批核准。复杂考试先完成官方机制与样题练习，避免假「全真」宣传。

**自动更新**：基于现有五源`competition-source-watch`，新增官方来源时采用有限站点白名单、合理访问频率、ETag/哈希去重，只创建**赛制变化或新试卷**审核事件；经核查才改最新规则。来源403/503不应阻塞普通网页、支付和作答。每周官方增量、每月覆盖矩阵，赛季开始/官方改版时专项复核。

**交付验收**：每项考试至少一份合法来源且可完成的端到端样卷；题量/时间/评分/空题/限制与官方文档完全一致；付费和游客权益不越权；进入→作答→交卷→报告实机通过；公网版本SHA和发布回执匹配才叫「正式上线」。

**本文件仅为研究与实施计划**；不更改现有生产考试记录、付费账本、敏感题库、监控任务或发布器。
