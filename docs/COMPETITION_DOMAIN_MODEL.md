# Math Competition Lab Domain Model

## First-class learning domains

The platform contains several parallel training domains. Arithmetic training is not a utility module; it is a first-class learning domain alongside competitions.

```
Math Competition Lab
│
├── Competition Domains
│   ├── Math Kangaroo
│   ├── Australian AMC
│   ├── MAA AMC
│   └── Other competition formats
│
├── Fundamental Skill Domains
│   └── Arithmetic / Calculation Training
│       ├── mental arithmetic
│       ├── calculation speed
│       ├── accuracy diagnosis
│       ├── strategy efficiency
│       └── adaptive practice
│
├── Solution Engine
│   └── AI explanation and visualization
│
└── Student Analytics
    └── unified learning profile
```

## Design principle

Competitions measure comprehensive mathematical ability. Arithmetic training builds foundational processing ability.

They share:

- student identity
- learning history
- analytics system
- adaptive recommendation engine

But they keep independent rules:

- Competition: official format, time limit, scoring, paper structure.
- Arithmetic: grade-specific targets, speed, accuracy, strategy diagnosis.

## Product navigation

The main entrance should present:

1. Competitions
2. Arithmetic Training
3. Student Learning Profile
4. AI Solution Studio

Arithmetic should not be hidden under competition pages.
