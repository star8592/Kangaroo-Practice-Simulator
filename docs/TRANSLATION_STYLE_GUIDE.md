# Translation Style Guide

本指南用于把葡萄牙语、德语、法语等袋鼠数学源题翻译成学生端唯一允许的两种语言：**中文（默认）**与 **English**。

## 核心原则

翻译目标是“忠实复现题意”，不是讲解题目。严禁补充提示、删减条件、改写数字、改变选项顺序，或根据正确答案反推题意。

## 中文

- 面向对应年龄学生，短句优先，避免生硬欧化表达。
- 保留必要的空间、方向、顺序、数量关系词。
- 数学术语使用中国大陆常见教材表达。
- `square / quadrado` 按语境译为“正方形”或“平方”，不得混淆。
- `cube` 译为“正方体”；`rectangle` 译为“长方形”；`triangle` 译为“三角形”。
- “图中”“下图”“右图”等指代必须与最终视觉资产保持一致。
- 人名可音译或采用中性中文名，但同一试卷必须保持一致。

## English

- 使用简洁、自然的 math contest English。
- 优先使用 `How many ...?`, `Which of the following ...?`, `What does ... see?` 等常见竞赛句式。
- 不使用复杂文学化改写。
- 保留题目原本的逻辑顺序，不把推理过程写进题干。

## 必须保持不变

- 所有数字和小数。
- 百分号、角度、货币、单位。
- A/B/C/D/E 对应关系。
- 加减乘除与等号、不等号等数学符号。
- 图中的拓扑关系和方向关系。
- 正确答案 key。

## 视觉题处理

1. 图形内无必要源语言文字：生成/使用 `diagramOnly`，题干与选项使用 HTML 中英文。
2. 图形内有必要文字：生成 `localizedZh` 与 `localizedEn` 两套视觉资产。
3. 数字、A–E、数学符号原则上保留原样。
4. 学生端禁止依赖阅读葡萄牙语、德语、法语等源语言才能解题。

## 不确定性

遇到以下情况必须标记 `needsReview=true`：

- 原文存在语义歧义。
- 图片中文字无法确定是否参与解题。
- 数量、单位、方向词在 PDF 文本层丢失。
- 选项与图形无法稳定匹配。
- 翻译后数字或数学符号无法与原文一致。

此时不得把题目标记为 `examReady=true`。
