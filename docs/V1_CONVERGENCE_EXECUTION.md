# V1 Convergence Execution

## Goal

Stop expanding architecture and move the platform into a usable product loop.

## Remaining milestones

### 1. Arithmetic Domain

Extract arithmetic capability into a stable training engine:

- question generation
- difficulty adjustment
- error diagnosis
- speed analysis
- next-session recommendation

### 2. Profile Integration

Connect existing learning records:

- competition attempts
- arithmetic sessions
- solution interactions

into the unified learning event pipeline.

### 3. Product Acceptance

Validate complete flow:

student login -> training/exam -> feedback -> profile -> recommendation

## Freeze rule

After the above flow works:

- core architecture frozen
- new competitions added as extensions
- new content added as data
- new visualizations added as modules

The project then moves from architecture development to product iteration.
