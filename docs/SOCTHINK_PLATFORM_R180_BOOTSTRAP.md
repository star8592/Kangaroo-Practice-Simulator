# SOC THINK R180 平台授权：独立数据库安装包

## 为什么先安装

生产发布器已拒绝在缺少授权数据库配置时切换 R180，但完整
授权应用还在 Draft PR。该独立安装包可以先作为普通主站更新上线，
不包含工作台路由、不改变现有教师、学生及家长登录。

## 安装包的边界

- 既有 PostgreSQL18 平台库的结构声明 013、最小权限声明 014。
- 一次性安装程序和完整的非提权模拟回归测试。
- 生产 socthink_platform 及两张授权表已存在；安装前只读核对。
- 不自动重建库、修改学习记录、创建教师授权或自动发布 R180。

## 正式执行

授权管理员核实本安装包已经经过 CI 并在生产 release 中可用后：

1. 在 /opt/socthink-releases/current 下，以受信管理身份执行：
   python3 ops/release/install_platform_authorization_runtime.py --plan
2. 完成服务器运维审批，以 root 身份执行：
   python3 ops/release/install_platform_authorization_runtime.py --apply
   程序先备份平台库，再创建专用非超级用户、校验真实数据库权限，
   生成本机随机密码与 0600 的连接环境文件及 systemd drop-in。
   不需在聊天中传输任何密码；不会自动重启主站。
3. 在获准的候选环境运行平台数据库只读预检，再由已有原子发布器
   交付 R180。真实手机微信教师首次关联、登出、换号、授权和撤权
   E3 通过后，才允许开启词语星球强制平台模块授权。

部分安装或备份失败时停止并保留诊断，需由获准管理员核验。
不得换用另一个控制 Agent 绕过管理审批，也不得把模拟微信回调
当成真实用户 E3 已经完成。
