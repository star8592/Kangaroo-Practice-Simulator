# SOCTHINK 大考试平台信息架构与字号改版方案（2026-10-31）

## 需求与现场审计

用户反馈上一轮统一宽度与蓝白风格良好，但文字偏小、顶部仍以历史数学竞赛服务为主，考试分类不清晰，无法直观分辨入口与可用资源。代码现状：顶部 NAV_ITEMS 把“考试大全、资料中心、数学训练、竞赛模拟、赛事管家、购买权益、我的账号”放在同一层级；只在次导航 FEATURED 放四个分类，漏掉另外三大领域。现有唯一分类事实是 `ASSESSMENT_DOMAINS`（7 大类）+ `EXAM_DIRECTORY`（53 方向，其中仅数学训练/部分竞赛 live）。主页默认只展示 school 的具体方向，手机分类为单行横向滚动而非完整可见。站内存在大量 10–13px 正文、操作标签和按钮文字。

## 方案比较、迭代与最终决策

A. 单层导航将 7 个类别 + 5 个工具并列：项目越来越多，阅读效率低、窄屏必溢出，拒绝。

B. 一级导航只保留“考试分类、找资料、开始练”，然后全部类别藏在一个 Mega Menu 中：桌面可以，但新用户看不到全貌，手机过于隐蔽，拒绝。

C. **采用：两层信息架构**。第一层是用户任务；第二层直接呈现所有 7 个考试大类。取消旧 FEATURED 手写四项，类别从唯一权威 `EXAM_DIRECTORY` + `ASSESSMENT_DOMAINS` 数据推导。手机在“菜单”中依次呈现任务入口 + 7 个分类；不依赖横向滑动才能找到后几类。主页提供 7 个类别总览，所有类别卡片指向真实目录锚点；仅已开放的方向可直接进入练习。第二层不会用“已开放”误导规划中的业务。

## 内容层级（唯一数据来源）

1. **类别层**：中小学学业与升学／国际数学竞赛／语言与国际考试／大学与研究生考试／职业技能与岗位实操／职业资格与公职考试／兴趣与综合能力，共 7 类；名称读取 `ASSESSMENT_DOMAINS`，顺序、方向读取 `EXAM_DIRECTORY`。
2. **方向层**：53 个具体考试/主题；只有对应 `DirectoryTopic.href` 存在才显示“立即练习/打开”并链接，planned 只显示“筹备中”，不能制造伪购买入口。
3. **资源层**：可用训练卷以 `resource-catalog` 从真实训练就绪库存导出；门户可以链接 `/resources`，不新建第二套题库。
4. **任务层**：`/assessments` = 全部考试；`/resources` = 现有真题/练习卷；`/arithmetic` 与 `/competitions` = 现有在线练习；`/events` = 数学赛事日历；`/membership` = 购买/权益（以服务器实际可售内容为准）；账号入口统一使用 `SessionNav`，不在主导航重复“我的账号”。
5. **最终动作**：先查分类/搜索 → 查看该方向真实开放情况 → 有内容则进入训练或试卷 → 看结果/权益。没有内容时明确告知准备中，不出现空白落地页。

## 顶部导航

- PC 第一行任务入口：全部考试、真题资料、在线练习（可键盘/触屏展开：计算训练、数学竞赛模拟、错题复盘）、数学赛事、购买与权益；右侧统一微信登录/账号。
- 第二行 “考试分类”+ 7 个真实领域入口（`/assessments#domain-*`），不再维护 FEATURED 手写四项。
- 手机菜单：首组“找什么/做什么”任务入口；第二组“按考试领域”全部 7 类；每组点击直达真页面；按钮和链接触摸面积不小于 44px；关闭、键盘 Escape、路由变化不保留悬浮层。
- 不新增多套导航注册表：站内主导航动作可配置在 SiteHeader，一切考试类别与状态只依赖原目录。

## 视觉排版

- 页面正文基准 16px 左右；导航 15–16px；分类、试卷、说明 14–16px；按钮/筛选 14–16px；关键标题层级分明；辅助时间/状态允许 12–13px，不再用 10px 作为重要的可见文字。
- 手机确保不出现全局横向溢出，文字放大不会挤掉账户、语言切换和菜单。
- 保留首页既定 1440px 最大容器及桌面/手机左右留白，不重做上轮配色，不触碰答题输入、评分或支付处理。

## 一次施工、真实验收

只改现有 Header、Home、Directory 及主要访客页 CSS，并改现有测试以对应新的意图导航，不新增框架、数据存储、服务或发布链路。E2E 覆盖七分类可见、真实目录锚点、练习展开、移动菜单、字体计算结果（桌面/手机）、搜索仍可提交、未开放方向不可误点、页面无横向溢出。正式发布通过唯一 main → CI → 自动部署/回退 → /api/release SHA 对账，不为视觉变更建立额外发布门禁。
