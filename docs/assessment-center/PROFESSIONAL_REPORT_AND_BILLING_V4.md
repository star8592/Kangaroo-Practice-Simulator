# SOCTHINK 测评 v4：产品边界、报告与收款

日期：2026-11-01。生产以 /api/release 的 SHA 与真实交易回执为准。

## A. 产品边界

- 心理特质与职业兴趣研究试测：/assessment-center。当前 IPIP-50 中文研究译稿与 RIASEC 框架原创30题。
- 原创认知和阅读任务是非标准化学习练习，不是标准智商测验、心理障碍诊断或招生评估。
- SQL 数据分析属于真实技能实训，已独立迁移到 /skill-labs/sql-lab。旧链接 /assessment-center/sql-lab 永久重定向，兼容已有用户。
- 每种测评都有独立题项、计分公式、解释模型与样式；不得把官方 O*NET 的证据冒充为我们原创 RIASEC 题项的验证。

## C. 免费与付费交付

免费答题：大五50题或职业兴趣30题；免费简报仅展示本问卷中相对较高的两个原始维度均值、简要解读、来源和未验证提示。

付费完整版：全部5或6个维度；每个维度真实原始题项与正反向得分证据、背景和解释、适合与不适合的应用场景、7天可执行的自我观察任务、作答一致性说明、源量表文献/许可/版本与常模缺失信息。支持浏览器打印或保存 PDF。

虚构公开样稿：/assessment-center/report-preview，标明示例不是任何真实个人的报告。

这些文本为独立编写的个人探索辅助内容，不声称临床诊断、IQ、预测职业成功、百分位、置信度或中国常模等级。

## D. 唯一收款与隐私架构

数据库增量为 ops/db/009_assessment_report_rights.sql，增加同一 billing_products / billing_orders / billing_item_entitlements 账本内的 report 类型。只有两个正式 instrumentId 能作为报告商品，不创造第二个账本；迁移本身不允许自动启用商品。

服务端商品目录返回真实 SKU 和价格，不构造假金额。现有微信扫码下单、官方支付结果独立查验、权益账本与买家微信会话绑定沿用正式主链。购买对应量表的详细报告权益后，该微信账号可重新测评、重新生成同一种报告，不重复扣款。交易与售后按正式数字内容协议，交付后无理由退款边界须明确，法定权利保留。

免费答题完全留在浏览器内存中、不落数据库；支付后用户主动点击生成完整报告才将本次答案发往本站服务端即时重新计分。服务端先核验已支付未撤销的购买权益，再生成详细文本，不保存原始答卷或完整报告到数据库，不发送第三方。刷新后答案消失，需要重新作答才能重生成。

## E. 上线标准

一、两套量表的免费简报、详细版式与出处说明可公开部署。
二、所有付费报告 SKU 在迁移及买家身份核验之前必须保持关闭。不能只靠显示购买按钮宣称收款成功。
三、生产付款启用必须获得迁移、真实报价、数字协议确认、微信官方订单回执、服务器权益授予、本人完整报告、非本人访问拒绝与退款撤权等真实证据；否则只展示免费简报和样稿。
四、相关自动测试：test:assessment-report，test:platform，隔离 PostgreSQL billing ledger，桌面及手机 Playwright E2E。必须发布到当前 GitHub main 的 CI 通过版本，不覆盖其他已合并项目。

## F. 利用现有的单微信买家真实试付（2026-11-02）

正式公网 Web Native 收款开关未打开时，原系统已具备 `nativeCheckoutAllowedForBuyer`：仅生产环境授权的一个微信买家账号与一个指定商品可以尝试真实付款，不创建新的支付账本或并行交易机制。报告商品报价接口现在**与现有正式下单接口复用同一个鉴权函数**，匿名、非白名单微信账号、其他商品均不能看到试付价格或创建订单。

报告上线准备状态与试付需分开：生产已完成 009 schema 迁移并备份恢复验收，两种报告是未启用SKU（试点拟价分别¥9.90/¥12.90），不自动打开售卖；正式授权、真实交付审核、已批准商品状态与单账号真资金回执未具备前，不能称为已收款。现有的 13 项资料SKU和原指定资料试付保持不变；不得为了测试报告擅自更换已有试付买家/商品。

商户正式认证只读证据：生产服务器签名查询不存在的订单返回微信官方 HTTP 404 / ORDER_NOT_EXIST，微信返回签名验真成功。**它证明连接和认证可用，但不证明 Native 下单与到账完整闭环**。未产生新订单或扣款。

更多实付操作以 `docs/engineering/NATIVE_SINGLE_BUYER_SMOKE_20261101.md` 和微信支付官方 Native 指引为准。
