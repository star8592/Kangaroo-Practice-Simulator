# SOCTHINK 九套测评专业可信度审查（2026-11-02）

## 审查范围与事实口径
当前 `/assessment-center` 有**9套具备实际可作答实现**的项目，另有独立的 SQL 技能实验室（不计入测评），心理状态与生活暂未开放。主分支此前技术登记8条，PR #252 补齐招聘通用能力后为9条。本次将原来六张大类卡片、四条隐藏附加入口统一整理为九张可直达的测评卡片。

现有软件功能的自动化验证，**不能**证明这些项目已具备中国本土常模或可用作聘用、升学、心理诊断的心理测量学效度。不得标注为“权威认证”“经过专业常模验证”“原版 SHL/Watson-Glaser 官方真题”。

| 招聘通用能力 40题 | 本站原创；通用招聘能力题型 | 本卷原始正确数及五类任务复盘 | 题项难度/区分度/时长、专家验证和职业效标 |
| 高级推理 40题 | 本站原创；SHL、Pearson/Watson-Glaser 公开能力分类 | 本卷原始正确数、错题证据 | 当前若干排序题过于基础，需改题及实测难度、分项可靠性 |

| 阅读与证据判断 16题 | 本站原创文章及证据片段 | 当次阅读错误、原文证据和训练建议 | 年龄/年级适用性、阅读难度与题项统计及校准 |

## 三种不同的“专业”
1. **可核验出处**：谁开发、原始方法/题项来自哪里、有无授权、谁负责维护、版本何时更新。来源不等于认证。
2. **测量学专业性**：构念、题目蓝图、专家内容效度、试测样本、难度区分度、信度、解释效度、DIF与公平性、有意义的常模。没有完成就明确显示“尚未建立”。
3. **产品专业感**：考试目录一目了然；考前说明短而完整；考试中保持品牌/方法链接、进度、题目、计时与操作清晰；报告可溯原题并支持留存。

## 首轮代码落实
- 九套项目在目录中一项一卡，直达考试及独立技术档案；方法来源和适用对象不藏在“更多”或二级小字中。
- `AssessmentTrustBrief` 在入场页展示开发责任、来源/授权、结果边界，并链接有依据的原始公开资料；全站不展示虚构注册、合作与认证。
- `AssessmentExamIdentity` 保证作答状态下仍能看到当前训练/研究属性及证据入口，避免把练习误作专业官方认证；桌面/手机共用轻量界面规范。
- 40题高级推理报告已在 PR #252 增加答卷完整性与基于错题的训练建议，其它报告逐项有不同程度的证据和边界说明，需继续按具体测评品类深化。
- 首页目前展示的9个项目对应 **9个技术登记条目**；用自动化合约检测两者一致，防止未来再把测评藏起来。
