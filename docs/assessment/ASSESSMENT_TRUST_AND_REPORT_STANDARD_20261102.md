# SOCTHINK 测评可信度与报告专业标准（2026-11-02）

## 用户目标
用户进入任何测评时，直接看到开发与运营主体的真实可核信息、测评开发历史/来源、方法、适用对象、题量时间、报告样例和收费范围；作答界面专业清晰；付费报告提供高于简要结果的可核验价值，不用虚假的资质和常模营造权威。

## 真实性优先
- SOCTHINK 作为产品/运营品牌已可公开。站点 https://socthink.cn/assessments 页脚公示「青梧未来（武汉）人工智能应用软件有限公司」「鄂ICP备2026004372号」。此为网站自行公示，尚未完成官方工商或备案系统实时比对；对外可准确标注为“网站公示主体”，并链接工信部备案查询 https://beian.miit.gov.cn/#/Integrated/index。**不要自行补造**统一社会信用代码、创始年份、专家姓名、执照、合作机构和第三方认证。
- 当取得已核实的工商/合同/专家参与证据后，再纳入官方“关于我们”页及可追溯来源。不要用“权威”“已标准化”包装自主练习。
- 明确区分 ①原创训练题 ②文献/开放题项研究试测 ③经实际校准的标准化测评；当前本中心尚无中国人群常模。
- 文献与标准是*设计参考*，不构成出版社授权、机构背书或产品认证。

## 面向用户的四个接触点（全站一致）
1. 列表卡片：测评目的、题量/时长、适用对象、免费/收费、验证状态；避免一长段营销文案。
2. 考前入场：品牌与真实开发责任、题源和方法、答题规则、结果边界、隐私与交付；只用短模块，详细内容链接到技术档案。
3. 考场：进度、剩余时间、导航、标记、完成/交白卷确认、清晰可读的选项与移动端布局。
4. 结果与报告：可核对的分数、已答/未答、题项证据、局限、训练建议、卷版本；与“标准化能力水平”严格区分。

## 专业测量学六个研究维度
- 构念与蓝图：说明为什么这些题能覆盖某种能力及内容比例；独立专家审查唯一答案与内容覆盖。
- 评分：计分规则、反向计分、缺失处理、异常和无效答卷一致性。
- 可靠性：在合适样本上测内部一致性/重测及测量误差，区分能力和题型；有数据后才公开估计及置信区间。
- 效度：内容、作答过程、内部结构、外部相关和后果，不能只用软件测试代替。
- 公平性：语言理解门槛、性别/年龄/地区 DIF、无障碍体验和差异影响，依目标群体调查。
- 版本维护：题目变更与版本号、验证样本、时间、适用群体、责任人、更新记录；历史报告不偷偷改写。

## 当前40题高级推理卷的分级
状态：原创正式模拟卷/训练材料（不是已校准的标准化测量工具）。
已验证：5×8结构、客观评分函数、客户端体验和空白0分等代码逻辑。
尚缺：跨人群/跨场景统计数据、专家盲审、试测难度区分度、信效度、计时影响、常模与分数解释研究。
允许：原始正确数、分维度 8 题记录、准确列示错题、复盘建议和当次表现。
禁止：IQ、百分位、胜过多少人、最佳岗位、高潜人才、企业面试通过率、科学认定的优弱势等级。

## 深度报告分层（收费须以真实商品和服务端权益开关为准）
- 免费结果：原始得分、作答/未答、基础维度和报告边界。
- 付费详细报告（**只在实际完成验证、上架且交付核验通过时开放**）：用户可见的更多题项级证据、跨维模式和理由、风险与解释边界、针对性训练方案、版本与评分算法、可留存PDF；服务内容购买前可用虚构样本完整预览。
- 不能利用无常模和无效度的训练卷售卖伪科学人物标签。付费价值是专业复盘与辅助训练，不是捏造的心理诊断。

## 迭代验收
- 无“公司资质认证”或“专家团队”造假；前台入口无需展开折叠即可看到责任/题源/用途边界。
- 空白、部分和完整答题的报告必须正确处理；空白不可生成能力判断；只有8题/维度不可生成稳定“强弱项”评级。
- 断点续答和手机端无溢出；报告每个行动建议必须能回溯错题或维度数据。
- 可核验真实购买、权益领取、报告交付后才宣称付费上线；本轮不改生产支付开关。
