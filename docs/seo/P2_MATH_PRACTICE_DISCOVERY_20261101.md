# SOC THINK：G1–G12 数学训练公开搜索入口（2026-11-01）

关联：全站 SEO＋GEO 正式 ADR；P0 抓取审计；P1 IndexNow 验收；P2 高质量原创内容入口。

## 1. 已证实的产品与搜索问题

- 现有 `/arithmetic` 是**真实在线训练主程序**，未持有会话的第一次访问会先 307 到游客会话初始化，再回到训练面板。这对真实用户可用，P0 已用 CookieJar 证明不能误报成循环故障。
- 但匿名无会话爬虫无法从 `/arithmetic` 的第一份 200 HTML 直接获得产品与课程内容；原 Sitemap 只有考试目录、资源专题、政策等，没有专门解释 G1–G12 计算训练的可索引页面。
- `src/lib/arithmetic.ts` 已有完整 G1–G12 的实际训练技能定义；`src/lib/arithmetic-grade-guide.ts` 已有各年级目标、练法与易错点；这些是唯一可复用的真实事实来源。

## 2. 本次架构选择

在现有 Next.js App Router 新增 `/math-practice` 公开服务器渲染入口（不要求 Cookie/登录），而**不重写 /arithmetic 训练主链路**。核心文案和 12 年级技能表从现有两份权威课程配置读取，不另造年级课程表和题库。

页面提供：
- 首页/产品导航可发现的常规 HTML 链接、完整标题/H1、规范 canonical、Sitemap 更新；
- 小学/初中/高中分组介绍、各年级真实核心技能、学习目标和常见错误；
- 20 题诊断→薄弱点训练→复测的一般学习流程（与已上线真实训练模式相符）；
- 引导到已有 `/arithmetic`，由原服务器负责游客身份与练习权限；
- 真实可见的 BreadcrumbList，两级路径；不编造评分、考试主办方认证或所谓官方课程批准。

只建立**一个有独立内容价值的公开长页**，不批量创建 12 个模板化、内容重复、没有真实用户价值的薄页。页内有 12 个模块，但 URL 只增加 1 个。

## 3. 版权、隐私、支付与技术边界

- 只公布本站自有课程描述与数学技能名称；没有题库题干/答案/私有 PDF、学生记录、订单、密钥或未授权原卷。
- 保留现有训练链接、游客启动机制、权限检查、数据收集与收费方式；SEO 发布失败不会阻止原有训练。
- 页面从已经发布的实际课程配置服务端生成；绝不能额外维护第二套内容库或再写一套用户账户。
- 维持中英文界面既有使用方式，但本次公开搜索正文优先中文；没有实体英文页面前不添加虚假 hreflang。
- 不以“发布已完成”冒充 Google、百度、Bing 已收录，也不把 IndexNow 通知当作收录率。

## 5. 延伸安排

待真实流量与用户搜索语句显示进一步需求，再考虑有充分内容价值的具体训练专题页。不要在未有差异化内容、收录数据和练习需求时机械批量制造“1年级～12年级”同模板页面。
