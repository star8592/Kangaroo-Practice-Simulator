# 闲鱼数学竞赛模拟考试：单次考试上线验收

## 商业契约

一场付费订单只对应一套被选中的 exam_id，一次限时考试以及一份诊断报告；刷新或断线继续相同场次，正式交卷后本次权益核销。按竞赛、年级建商品，按年份及场次建立独立 SKU，订单商品 ID 与真实所选 SKU 必须同时准确核对。

生产闲鱼消息、付款状态、无需寄件发货以及买家聊天回读继续由独立 Android 机器人执行；服务端只管理已核对订单的考试权益与报告。

## 本轮开发证据

- scripts/test_exam_entitlement_flow.ts：单次授权、重复请求防重、错误年份防串单、交卷核销。
- scripts/test_commerce_provision.ts：模拟订单鉴权，正确一年一次开通，错误权益数量和年份拒绝。
- scripts/test_single_paid_exam_e2e.ts：隔离合成自有卷的开通、进入、限时提交、评分和完整诊断对象生成。
- scripts/test_exam_submit_recovery.ts：已有交卷恢复与并发锁回归。
- tsconfig.single-exam-check.json：改动范围 TypeScript 编译检查。
- scripts/test_full_original_mock_e2e.ts：走美杯风格 G6 2026 A 卷、华赛高阶 G6 2026 B 卷的 15 题完整考试、1 次权益核销、逐题解析和 PDF 真正渲染。
- 两份由自有试卷 + 合成考生生成的报告均实际导出 **15 页 A4 PDF**，各含 **15/15 条已审核题目解析**；华赛报告逐页确认 15/15 个连续页脚、所有解析均存在。用户数据和正式题目内容未写入 Git。
- PDF 报告把“答题行为与时间管理”和“逐题状态速览”分别独立为一页，解决早先因为分页溢出产生额外残页的问题。


以上全部属于开发环境，不代表真实闲鱼支付、上架或 PDF 浏览器正式渲染通过。

## 私有试卷内容与部署

开发环境已验收加载原创走美杯风格六年级 2026 A 卷（15题，90分钟）及原创华赛高阶六年级 2026 B 卷（15题，120分钟），并以非官方原创仿真标识。私有文件保存在服务器端 private/commerce-exams 目录，不纳入公开 Git 仓库。正式部署需受控同步私有数据，并进行文件哈希及实际题目 QA，缺失原卷即不可开通。

原 SEAMO 修订版属于基础训练而非高仿真正赛规格，其他历史题库不能仅凭可加载即计作收费可售内容。

## 当前禁止声称完成的步骤

1. 闲鱼真实商品与年份 SKU 及订单支付证明回读。
2. Android 解析具体购买年份和 SKU 的独立实机验收。
3. 生产服务器完整私有试卷加载、计时、答案和来源标签审校。
4. 真正订单触发发放一次权益，完成考试并生成 PDF，在原生聊天中送达并回读。
5. 上述未通过前，商品维持草稿，不能激活线上收费权益。

此分支在独立工作树开发，不直接替换线上服务。
