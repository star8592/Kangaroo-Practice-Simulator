# 赛事管家与竞赛模拟职责边界

版本：2026-10-12。范围：SOC THINK Web 与微信小程序。

## 顶部/底部导航

- 数学训练：/arithmetic；竞赛模拟：/competitions；赛事管家：/events；数学成长：/student。
- 小程序的“模考”和“赛事”保持独立 Tab；页面内分别说明功能及跨模块入口。
- 首页任何“查看赛事/赛事管家”卡片必须落在 /events?event={eventId}。
- 历史 /competitions?event={eventId} 仅作向 /events 的兼容重定向，不得继续在模考页面复制赛事管理器。

## 服务边界

赛事管家负责：统一全球赛事目录（中国与国际平等）、资料出处、逐届资格与场次核验、关注、赛历、报名准备、行动清单、成绩/证书管理。未核验报名时间不得标为已开放，不得虚构倒计时；用户关注不等于报名成功。

竞赛模拟负责：已入库的国际数学竞赛赛制、试卷、评分、复盘和错题。页面不展示独立的赛事目录、关注管理器及参赛报名倒计时。

**中国赛事仅提供信息服务，不在本站提供中国赛事试题、题解或在线模拟。** 当前注册表中，所有 `region === "CN"` 赛事都不得拥有 `trainingId`；测试必须保证该约束。对国际赛事，也只有真实可用的试卷才出现进入站内模拟的入口。

## 数据与路径

- 两个业务依靠 `eventId` / `trainingId` 单向关联，保留现有用户关注、待办、成绩和权限记录；不得为界面迁移重复建立用户数据。
- 赛事管理指向 `/events?event=...`；已可用的国际模拟从管家跳 `/competitions?c=...`。
- 登录前后返回地址指向赛事管家；身份认证和付费/完整考试权限仍由服务器执行原有门禁。
- Web 与小程序均保留中国赛事的信息服务路径；小程序模考不放“我的赛事流程”重复卡片。

## 最小验收集

1. 中文/英文导航和首页卡片路由正确；移动端菜单可点击。
2. 逐地区/学段/关键词筛选赛事；筛选为空时不展示错误的赛事详情。
3. 中国赛事仅显示来源和参赛信息；没有站内模拟入口。
4. 国际模拟仍按赛制选卷、进入原有权限门禁。
5. 登录学生关注 → 赛历 → 返回详情 → 取消关注，全流程成功。
6. 旧分享链接仍打开原赛事；小程序五 Tab 和赛事/模考互跳继续可用。
7. TypeScript、ESLint、相关契约测试和桌面/移动端 Playwright 通过方可交付 PR；生产发布遵守统一发布门禁。
