# 微信小程序体验版连接诊断

## 目的

用户实测按钮、计算训练和竞赛目录无响应时，服务器端 API 成功不代表微信客户端真正联网成功。现有 Z890 Linux 无官方微信开发者工具，需收集 **微信设备本身** 的请求结果，不能将服务器探针冒充端侧 E2E。

## 进入方式

微信**开发版/体验版** → 我的 → 一键连接诊断 → 开始连接诊断。正式发布版不显示入口，诊断页面在正式版也不能执行检测。

诊断依次做：
1. 微信原生 wx.login，仅记录是否拿到 code，不保留/展示 code；
2. 使用 code 请求后端 /api/auth/miniapp/wechat，判断身份是否连接；
3. 如果微信身份失败，尝试 /api/auth/miniapp/guest，以独立区分后端域名不通与微信身份故障；
4. 用临时身份请求 /api/miniapp/exams，核实真实试卷数量；
5. 用临时身份启动一年级 20 题诊断（不提交答案、不保存成绩）。

请求错误自动识别“微信 request 合法域名未放行”、超时和其他错误。显示每步 HTTP 结果，支持复制匿名诊断报告。不会复制 OpenID、accessToken、微信登录临时代码、用户实名或题目答案。

请求目标为 https://socthink.cn，必须在微信公众平台「开发管理 → 开发设置 → 服务器域名」添加 **request 合法域名**。微信 OpenAPI 后端出口 IP 白名单是另一层配置，不能混淆。

## 不能替代的质量门禁

这是一种真实设备网络诊断功能，不是完整真机自动 E2E。完整计算答题提交、竞赛交卷、复盘、异常恢复仍需按照 scripts/verify_miniapp_qa_receipt.mjs 的证据要求验收。绝不根据此诊断功能的构建/运行自动生成 QA PASS 凭据。
