# SOC THINK 考试与测评视觉统一规范

版本：2026-11-02 · 主体：综合考试、人格与职业兴趣、认知推理、阅读训练、岗位技能、报告。

## 一条界面主链路

- 全站页面容器：复用 `src/app/globals.css` 的 `--layout-standard`（1440px）、`--page-gutter`，不得再在局部页面另设固定 1220px 容器与不同左右边距。
- 专注作答内容：`--layout-focus`（960px），减少视觉横跳；SQL 工作台可用宽幅双栏。
- 色彩：仅使用全站 `--portal-*` 设计变量；不复制一套孤立的青色、灰蓝色按钮/面板体系。
- 字阶：目录名称 23px，主要题干 23–30px，重要操作 15–16px，题量与进度 14px；不要把最重要信息缩成装饰性小字。
- 首页：保留简洁的“科学测评 / 选择测评”结构。不要加入大段口号和所谓热身说明。方法资料应放在可展开的证据区。

## 流程

1. **了解测评**：题量、估计用时、用途、年龄限制和收费边界；专业来源与许可证可展开查阅。
2. **逐题作答**：单屏主问题、五档响应、真实已答进度、可展开答题卡、返回修改、全部答完才提交。
3. **查看结果**：免费简要结果；完整报告由原有服务端商品与权益控制，不由 UI 自行放开。
4. **打印与阅读**：付费报告保留排版与独立打印；显示来源、计分方法、科学限制。

不同产品只统一框架，不强制统一题量、时间、评分或心理测量解释。人格与兴趣研究试测不得伪装成中国本土标准化量表、IQ 或临床诊断。

## 必做验收

- 宽屏、平板、手机（1440、768、390px）无水平溢出，目录、试测入口、答题区都与站点容器对齐。
- 测评目录、人格 50题、职业兴趣30题、认知推理、阅读、方法档案与付费报告样稿均能访问。
- 未答题不能提交；回答能修改；答题卡跳转不能丢答案；免费简报与详细报告购买权限不混淆。
- 通过 `test:measurement-center`、`test:assessment-skills`、`test:assessment-reading`、`test:assessment-report`，再做构建、移动端检查。
- 发布遵循 GitHub main → 原子部署 → SHA 和公网实际页面核验；未上线不得声称已上线。
