# SOC THINK 经营驾驶舱 · 实施与指标契约（2026-11-01）

## 产品定位

现有 `/admin` 成为正式运营/财务/增长统一入口；`/admin/seo` 保持专门的搜索诊断页面。管理员一次登录，无第二账户、第二数据库或第二发布链。

按运营决策优先级组织为 **付款结果 → 用户增长 → 搜索获客 → 内容与商品供给 → 待处理事项**。界面保持高质量一致的层级与手机适配；避免大量颜色和全是“0”的伪报表。

## 真实指标来源与边界

| 实收订单额（经营口径） | 唯一 PostgreSQL `billing_orders` | `state='paid'` 且 `paid_at` 在滚动 N 天内，使用订单 `price_minor`，当前退款订单不计入 | `—` + 账本未配置/无法读取，绝不能显示 0 |

### 收款口径特别注意

此处不是财务报表的收入确认和净利润：它是**目前状态仍为 paid 的已核验订单金额**。后续某笔订单退款后将从历史窗口的“有效已支付”汇总中消失，所以同一个历史窗口重算有可能变化。会计确认收入、现金流/退款流水需单独设计正式对账口径，不可以从页面访问量估算。

只有 CNY 进入人民币总 KPI；其他币种独立列示，不在未经验证的实时汇率下汇总。ISO 币种的小单位精度按币种处理。

## 界面契约

- 页面 `/admin?days=7|30|90`，默认 30 天，服务器做参数归一化；用户可读地说明时间窗口。
- 手机/平板/桌面响应式，核心收款指标必须放在第一屏。
- 每个章节有明确来源、口径；无数据不作假曲线。
- 用户、订单、微信 OpenID、私密试卷等明细不进入该总览响应。
- 无权访问则使用现有 Cookie + `isAdmin`，`/admin/login` 登录；robots noindex 且 `robots.txt` 禁止 /admin/。
- 数据在服务端从现有真源读取；没有单独的运营 JSON 数据库，不增加前端滥刷 API。
- 账本一部分故障必须保持其它模块可用：`readAdminRevenue()` 单独返回 unavailable，不将异常转为零。

## P2：订单转化诊断与商城实物核验（2026-11-01）

本批所有新增监测均只读现有权威数据，不引入埋点数据库、收费中间层或重复轮询。新增：

- **订单同群组漏斗** `src/lib/admin-checkout-funnel.ts`：基于单一 `billing_orders` 表，仅统计选定的 7／30／90 天**创建的订单**，按币种、支付渠道和产品类型分组，显示当前已付、待付、关闭、退款、超过 24 小时仍待付数量，且校验各状态之和等于创建数。分组聚合不输出用户、订单、交易 ID。
- **当前有效付款占比** = 当前 `state='paid'` 的 cohort 订单数 / 同批创建订单数。它不是流量转化率；用户未完成扫码、订单状态改变或退款时都可能改变该指标。创建订单数为 0 显示「—」，数据库连接错误时整个状态为「不可用」，不是 0%。
- **当前收款入口配置**：来自 `nativeCheckoutAllowed()`。历史已支付订单对账**配置**来自 `nativeSettlementAllowed()`。这些是纯开关，不等于微信商户授权实时有效或服务正在运行；保留原有真正结算 timer 作为唯一正式对账处理器。
- **真实可展示商城商品**：`readStorefrontAvailability()` 与公共 `listStoreProducts()` 共享同一版权、配置、资料文件真实性检查，只有实际出现在商城的已核验资源才计入展示数。数据库异常时区分 `unavailable`，没有配置时区分 `not_configured`；原公开商城继续按 fail-safe 空列表呈现。
- 运营行动中心：根据实际超过 24 小时待付款的订单数提示对账检查；收款开关未启用时提醒核对资质和支付配置；真实商城可展示商品为 0 时优先补货；商城查询不可用时报告异常而不是显示 0。**不**自动关闭、重试、退款或改变生产订单。

新增测试 `scripts/test_admin_checkout_funnel.ts` 覆盖分组币种隔离、状态人数计数、0 分母、源不可用语义。原有 CI、部署与验收流程不变。

### 还未取得的数据

真实“搜索曝光→访客→加购→创建订单→支付成功”全路径转化，必须等待合法的第一方访问事件、归因 ID 以及官方搜索平台 API 完成验收；不能用本次已创建订单 cohort 冒称访客转化率。支付 worker 进程活性、真实微信查单成功率、消费者实际下载交付完成率等指标后续必须另有可靠证据源，不能直接推定。
