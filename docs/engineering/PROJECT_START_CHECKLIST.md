# Project Start Checklist

Before implementation begins:
- [ ] External systems and integration surfaces identified.
- [ ] Current official docs and first-party examples reviewed.
- [ ] `external-spec-baseline.tsv` populated with URL/version/review date.
- [ ] Requirements matrix written from authoritative sources.
- [ ] Assumptions registered and classified as SPEC / OBSERVED / INTERNAL / ASSUMED.
- [ ] Material ASSUMED items have an explicit research/verification plan.
- [ ] Architecture/ADR cites the authoritative constraints it depends on.
- [ ] Contract/conformance tests are defined before implementation.
- [ ] Negative/failure-path tests are defined.
- [ ] Real target-host E2E acceptance is defined.

Implementation may begin only after the applicable items above are complete.
