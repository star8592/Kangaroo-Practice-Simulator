## P0 根因（已确认）
- 生产部署 `b5984e5c050eccc71de1ec57d0ac5e2f4dcf109b`、`https://socthink.cn`。
- Windows 模拟器 `wx.login` 成功产生临时代码；POST `/api/auth/miniapp/wechat` 返回 **HTTP 503**、`reason=wechat_ip_whitelist`。
- 后端 `classifyWechatCode2SessionError(40164)` 将微信上游 40164 分类为白名单阻断；生产 `journalctl` 有多次一致日志。
- 实际生产服务器 SSH `root@socthink.cn`，对外经 ifconfig.me 检测 **8.166.137.232**；需在当前小程序账号配置**微信服务器 API 调用 IP 白名单**，不能混同代码上传 IP 白名单。需管理员完成平台配置后，用真实 wx.login code 复测。
- 作为对照：签发一次性游客测试令牌后，生产 `/api/miniapp/arithmetic/session` 的 adaptive start 返回 HTTP 200 和 12 道题，证明计算生成服务可用；但不能代替微信登录入口的成功。

## 本 PR 解决的另一条独立故障
- 无须登录的赛事目录、试卷**元数据**目录允许匿名读取，不再先触发失败的微信登录；拥有令牌时依旧能读取自己的赛事进度。
- 站内考试启动、答题、成绩、权限不改。测试继续断言游客无完整考试权限。
- 小程序公开赛事目录隐藏 CN 国内赛事；旧资料暂保留在内部数据源中用于历史兼容，不作为小程序公开列表。
