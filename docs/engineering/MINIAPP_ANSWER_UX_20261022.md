# 小程序做题流程修复验收（2026-10-22）
## 用户发现的真实问题
Windows 微信开发者工具用 `miniprogram-automator` 真实进入计算训练后，按钮树同时出现 2 个“提交答案”，分别来自 `ArithmeticAnswerPad` 内部和题目外部（大按钮）。已确认问题，不得把 CI 绿灯说成 UX 验收完成。

## 产品策略
- **计算训练**：仅保留页面底部大号提交按钮，数字键盘只负责输入；答题时显示“暂存并退出”并二次确认。训练存到当前用户独立设备空间（原始题目、当前输入、反馈和已完成作答），最长可恢复约 3 小时 45 分钟，短于服务端签名会话 4 小时有效期。跨账号、过期、结构异常均拒绝恢复；切换到新一轮必须告知会取代原暂存。
- **竞赛模拟**：单独提供“保存并退出”，明确提示本地暂存且计时不会停止；“交卷”是独立的不可逆动作，一律二次确认。全部空题时明确“确认交白卷”，但**不能笼统声称交白卷分数为零**，有些考试含起始分、空白题计分。
- **成绩与复盘**：交白卷后可直接返回模考，不生成掌握度诊断；查看原题和解析是自愿行为。复盘里的“未作答”不标为“答错”，可直接看答案而无需强制重新提交；已作答错题仍可自主重做或跳过。
- **边界**：保留服务器权限、会话标识和去重交卷逻辑；未提供考试答案的提前泄露路径。线上发布前必须通过微信开发者工具真实按钮点击，尤其需检查新 UI 文案和弱网/退出恢复。
