# SOCTHINK 全站视觉一致性基准（2026-10-31）

## 目标与范围

原先单一数学竞赛网站已升级为综合考试、资源与在线练习平台。此次以 **正式首页** 为视觉基线，对全站 Web 的共同框架进行结构性统一，而不是逐个页面堆叠 CSS 补丁。所有对外页面遵循一套导航、内容对齐线、配色与移动端留白；页面高度与内部工作区布局可按任务不同。

## 已核查的代码来源与具体差异

- 首页：`src/components/PublicHome.tsx` + `PublicHome.module.css`（综合考试门户）；首页原来在全宽背景内独立设置 1440px 的内区宽度，和顶部导航的内容对齐线不同。
- 考试大全：`AssessmentPortalClient` + `assessments.module.css` + `ExamDirectory.module.css`，两层组件各自定义 `width: min(1440px, calc(100% - 56px))`。
- 资料中心：`ResourceLibraryClient` + `resources.module.css`，单独设置容器宽度、外间距、移动端填充。
- 购买与权益、账号：两个独立 CSS Module，各自再实现一次宽度/留白规则。
- 竞赛模拟、赛事管家、计算训练、报告、教师后台：主要依赖 `globals.css` 里历史 `.home-shell` / `.report-shell` / `.student-shell` / `.admin-shell`，其中 `--layout-standard=1200px` 与新版首页的 `--layout-wide=1440px` 冲突。
- 登录：`AuthExperience.module.css` 仍保留旧绿色登录标识/灰绿文字；其表单保持紧凑以利于扫码，是合理的内容宽度例外。
- 法律与售后条款：先前将整页压在 820px，导致标题无法与首页对齐；现在外壳遵循同一宽度，但正文保留有限行长。
- 考试作答、A4 打印：内部答题区/纸张尺寸属于功能性约束，不应强行扩张至门户栏宽；只统一外围容器与通用样式，不触碰题目评分、打印分页和交互流程。

## 统一的布局契约

1. 页面内容外框最大宽 **1440px（包含左右内边距）**；在大屏幕水平居中。
2. 桌面共用左右 **28px** 留白，小屏（宽度 ≤760px）共用 **14px** 留白；中间尺寸也统一到导航基准，不出现子页独有的 20px 对齐偏差。
3. 主色取自首页：`--portal-navy`、`--portal-blue`、`--portal-blue-strong`、`--portal-canvas`；正文、分隔线、交互焦点统一到对应设计变量。
4. 通用按钮正文必须保持白色与蓝色背景的可读对比；绿色/红色仍仅保留正确性、状态与风险等语义功能。
5. 页面可以拥有不同的栏目密度和高度，但共享 Header / Footer / 内容对齐线。登录表单、试卷阅读、考试答题和打印可拥有**内部**的任务专用宽度。
6. `data-site-shell="content"` 用于标记主体内容边界，是仅供回归测试的稳定语义锚点；不影响既有页面业务 API 或访问权限。

## 覆盖清单

| 类别 | 路由/页面 | 统一方式 |
| --- | --- | --- |
| 综合门户 | `/` | 首页最大宽度与公共导航一致 |
| 考试检索 | `/assessments` | 目录、筛选和说明使用一条内容线 |
| 试卷资源 | `/resources` | 搜索、卡片、分页沿用首页内容线 |
| 购买权益 | `/membership` | 购买说明、商品卡片及结算区同宽 |
| 账号订单 | `/account` | 共用主页内容宽与配色 |
| 竞赛与赛事 | `/competitions`, `/events` | 历史 `.home-shell` 宽度收敛到 1440px |
| 数学训练 | `/arithmetic`, `/arithmetic/session/[grade]` | 公共容器收敛，操作面板维持专用布局 |
| 成绩报告与复盘 | `/student`, `/review`, `/report/[attemptId]`, `/result` | 标准容器与蓝色通用主题 |
| 登录 | `/login` | 旧绿主题转蓝；扫码/认证界面保留聚焦宽度 |
| 管理台 | `/admin/*` | 外围容器使用同一最大宽，表格可横向局部滚动 |
| 协议政策 | `/terms`, `/privacy`, `/digital-purchase-policy` | 页外壳对齐首页，文章保留 820px 阅读行长 |
| 打印 | `/arithmetic/print/*` | 不更改 A4 页面内部打印规格 |

## 自动回归

`tests/e2e/portal-layout-consistency.spec.ts` 在 **390px 手机**和 **1440px 桌面**两种宽度，对首页、考试大全、资料中心、购买权益、竞赛模拟与赛事管家检查：
- 主体左右内容边界与首页偏差不超过 2px；
- 不发生页面级横向溢出；
- 页面有非零的可用内容宽度。

仍需在真实可运行的生产同版上做视觉截图验收，重点观察 Safari/iPad、长中文标题、筛选弹层、未登录状态、桌面高分辨率、大题图和 PDF 打印。此文档不将仅修改 CSS 误写成线上验收通过。

## 发布约束

此工作放在独立分支，避免与支付和 503 问题修复支线同时改动生产部署。合并前跑既有 `portal-surface-consistency.spec.ts`、`assessment-platform-portal.spec.ts`、新布局回归及页面截图抽样。若当前生产分支正在发布，先对比主分支并解决样式差异，**不以强制推送或抢占生产发布器完成本工作**。
