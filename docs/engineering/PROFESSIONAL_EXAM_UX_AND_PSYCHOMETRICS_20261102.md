# SOC THINK 正式考试系统与科学测评专业化规范（2026-11-02）

适用：数学竞赛模拟、校内测评、语言考试、岗位实训、人格及职业兴趣测评。统一交互基础设施与视觉设计，不统一不同考试的题数、时间与评分。

## 官方对标

1. Cambridge International Digital Exams: https://www.cambridgeinternational.org/programmes-and-qualifications/developing-digital-exams/support-and-guidance-for-digital-exams/
   导航、工具和题型有体验教程；不同题型允许不同工具、音频和导航限制，自动保存与无障碍支持依赖正式平台能力。
2. Cambridge OCR on-screen tests: https://ocr-live-prd95.cambridgeassessment.org.uk/administration/cambridge-technicals/assessment/on-screen-tests/
   答题卡区分当前、已答、未答、已标记；题目可复查；交卷前检查标记。
3. ITC/ATP Guidelines for Technology-Based Assessment (2025): https://www.intestcom.org/page/16
   测验有效性、公平性、易访问性、隐私、数字交付及计分需要证据。
4. WCAG 2.2: https://www.w3.org/TR/WCAG22/
   键盘可操作、焦点可见、触控控件和对比度。本站追求这些要求，但不能未经完整审计声称认证合规。
5. AERA/APA/NCME 标准: https://ncme.org/resources/books/testing-standards/
6. O*NET Interest Profiler 技术手册: https://www.onetcenter.org/reports/IP_Manual.html
   O*NET 的信效度和常模属于其特定题项与样本；本站自编 RIASEC 30 题不得冒用这些统计证据。

## 正式考试生命周期

1. 考前确认：考试和卷面版本、题数、计时规则、跳题与分段规则、免费或付费范围、官方/模拟/训练性质。
2. 作答：考试名称、真实剩余时间、清晰题干及录入区、已答/未答/复查状态，屏幕黄金位置不用大量口号占据。
3. 导航：题号直达、上一题/下一题、待复查标记；手机默认折叠题号导航并置于题卡前。除真实赛制限制外允许跳题。
4. 交卷检查：显示已答/未答/标记数，从弹窗直达未答和标记题。提交需要明确确认；分段锁定与倒计时由服务器主链控制。
5. 报告：客观题分数有真实来源和答案证据；心理量表没有经过验证不得提供全国百分位、智商、诊断或职业成功率。

## 适用产品差异

- 竞赛模拟：按主办方版本、赛制与年份维护规则；不可在“统一”时丢弃真实的分段计时、语言及独特题型。
- 能力训练：可允许不限时练习及复测，但不得冒充正式考试。
- 人格与兴趣：逐题作答→可跳题→标记复查→交卷检查→确认提交→免费简报→可选择购买详细报告；未答完不计分。
- 心理状态筛查：无适当资质和内容验证前不得生成疾病标签或医学诊断。
- 岗位实操：SQL 用隔离执行与可复现实测证据，不要混入人格测评。

## 心理测量的证据分级

- research-preview：来源、题项许可、计分规则、版本及局限公开；当前大五与自编 RIASEC 仍为此级。
- translation-reviewed：双向翻译、专家审核、认知访谈、适用人群与文化表达审查；此级仍不是常模验证。
- psychometrically-evaluated：公布样本设计、信度与效度、测量不变性、误差与质量限制，由独立专业人员复核。
- norm-referenced：只有在适当年龄、语言、地区和样本的真实常模经验证后，才可显示明确参照范围及不确定性。
- 付费报告可以提供全部真实维度、作答证据、方法、误差与可执行观察行动；不能出售虚构诊断/证书/成功率。

## 本轮代码

- 心理探索：新增标记复查、检查整张答卷、明确最终提交；未答完禁止提交；只保存在当前页面内存，不声称云端自动保存。
- 正式数学考试：移动端把折叠题号导航放到题目上方；交卷弹窗可直达未答题或标记题；进度条代表真正已答题比例。
- 以上只改变 UI 与导航，不修改正式考试后端计时、分段锁题和计分。
- 禁止在未真正验证前声称上线、常模有效、心理医疗诊断能力，或声称已取得第三方考试授权。

## 后续架构

新增考试定义独立的 ExamFormat：时间/分段/跳题/复查/题型/评分/提交的可组合规则，并携带出处与版本。先全面审计已有真实赛制和考试 Session 契约，再考虑抽象公共运行器；坚决避免大组件里持续堆叠特殊分支导致回归。发布按 GitHub PR、整站测试、原子部署与自动回退进行。
