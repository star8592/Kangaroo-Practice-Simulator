# 学习体验 R1：让初高中显眼、让统计真正有用（2026-10-22）

## 用户与问题
家长和学生进入首页，首先需要知道本平台是否包含自己所处的阶段；进入后首先需要知道怎么开练。旧小程序虽然包含 1–12 年级，但没有明显提示支持初中和高中；首页优先显示轮次、综合训练指数、数据置信度和累计题数，用户难以据此采取行动。

## 界面信息层级
**第一屏**：小学（1–6）/ 初中（7–9）/ 高中（10–12）明确展示、一个主按钮“开始计算训练”，内容示例来自实际年级训练体系。采用中文学段与 1–12 训练分级；其他国家年级采用独立跨国对照，不能偷换课程等效概念。

**今日行动**：用真实已有记录给出唯一下一步，未完成计算训练先做 20 题诊断；有记录但证据不足只建议继续短练；有实际训练总结才显示具体建议，且不把它称作竞赛预测。

**用户自选报告**：我的学习档案优先显示“接下来最值得练什么、依据是什么、当前结论是否可靠”；累计轮次、正式模拟总数和行为统计点击“展开详细记录与依据”后才出现。Web 学生档案同步以行动优先，把原 KPI 和诊断证据放入可展开区域，保留完整专业数据而非删掉它。

## 风险边界及验收
- 所有建议须来自已实现的 student analytics API，绝不假设具体弱项或虚构成绩。
- 计算训练和正式模拟保持分开，正式模考的计分、留空题和难度不可简单混算。
- 学段中文分组和 K12 国际 crosswalk 分开管理；不能暗示跨国年级、课程完全等同。
- 家长查看证据属于可选择功能；登录不新增流程、不改已有权限规则。
- PR 仍为 Draft，Z890/Windows 真机逐按钮回归、完整 CI 是合并与发布门禁。
