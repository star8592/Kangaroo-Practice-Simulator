# 微信优先的统一登录与注册体验（2026-10-12）

## 统一入口
- Web 访客导航和首页只显示「登录 / 注册」，默认微信扫码并在加载页面时自动准备二维码；在微信客户端内访问时直接走微信网页授权。
- 原学生账号/PIN、家长邮箱登录/注册收在可展开的其他方式，保留旧 URL 与原有考试 next 回跳。
- 首次通过微信识别身份自动建号，不预先询问家长/学生身份、昵称、邮箱、手机号或年级。

## 会话安全
- 微信网页服务号基本 OAuth 使用 snsapi_base，登录只要 OpenID，不为登录索取头像、昵称。OpenID/UnionID 只用于服务端身份关联。
- Web 会话使用签名令牌与 HttpOnly / Secure / SameSite Cookie，保留 30 天并在有效活跃会话上自动续期；登出/撤销/停用后不能恢复旧 token。
- 扫码票据一次性、过期无效，保护 OAuth state，安全校验本地 next URL，不信任任意外部跳转。
- 小程序 wx.login 换取服务端 code2Session 建立真实稳定微信身份。曾缓存的 guest 保存备份后自动尝试微信，失败提供重试，不再默默创建新 guest。
- 不把 AppSecret、session_key、明文 OAuth code 等敏感值写入客户端、日志或 Git。

## 验收与风险边界
- 检查桌面/移动 Web 首页统一入口、二维码自动呈现、旧账号登录以及游客无法绕过完整考试门禁。
- 检查登录持久性、会话续期、退出与撤销；小程序四种冷启动场景：全新用户、旧 guest、旧正式学生、认证失败。
- 通过微信开发者工具与实体安卓测试才能上传新版小程序，不得以编译通过替代实机证据。
- Web 家庭账号与旧学生学习档案不自动绑定；一户多孩子需要用户明确选择并验证旧账号。数据绑定、迁移、解绑是下一项独立交付，不能在此次 UI 改造时暗中合并。
