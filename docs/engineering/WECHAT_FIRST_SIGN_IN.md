# 微信优先的统一登录与注册体验（2026-10-12）

## 统一入口
- Web 访客导航和首页只显示「登录 / 注册」，默认微信扫码并在加载页面时自动准备二维码；在微信客户端内访问时直接走微信网页授权。
- 原学生账号/PIN、家长邮箱登录/注册收在可展开的其他方式，保留旧 URL 与原有考试 next 回跳。
- 首次通过微信识别身份自动建号，不预先询问家长/学生身份、昵称、邮箱、手机号或年级。

## 会话安全
- 微信网页服务号基本 OAuth 使用 snsapi_base，登录只要 OpenID，不为登录索取头像、昵称。OpenID/UnionID 只用于服务端身份关联。
- Web 会话使用签名令牌与 HttpOnly / Secure / SameSite Cookie，保留 30 天并在有效活跃会话上自动续期；登出/撤销/停用后不能恢复旧 token。
- 扫码票据一次性、过期无效，保护 OAuth state，安全校验本地 next URL，不信任任意外部跳转。
- 小程序 wx.login 换取服务端 code2Session 建立真实稳定微信身份。曾缓存的 guest 保存备份后自动尝试微信，失败提供重试，不再默默创建新 guest。
- 不把 AppSecret、session_key、明文 OAuth code 等敏感值写入客户端、日志或 Git。

## 验收与风险边界
- 检查桌面/移动 Web 首页统一入口、二维码自动呈现、旧账号登录以及游客无法绕过完整考试门禁。
- 检查登录持久性、会话续期、退出与撤销；小程序四种冷启动场景：全新用户、旧 guest、旧正式学生、认证失败。
- 通过微信开发者工具与实体安卓测试才能上传新版小程序，不得以编译通过替代实机证据。
- Web 家庭账号与旧学生学习档案不自动绑定；一户多孩子需要用户明确选择并验证旧账号。数据绑定、迁移、解绑是下一项独立交付，不能在此次 UI 改造时暗中合并。

## 2026-10-12 家庭首屏与可恢复基础训练（增量）
- 微信扫码成功默认进入家庭学习首页，首先展示「开始计算训练」，其后才是学生档案管理、PIN 和报告管理。移动端直接显示 50px 高触控按钮；统计/报告微文案保持可读。
- 当浏览器已有有效家庭会话、没有独立正式学生会话时，服务端签发稳定的 **guest_family** 基础练习身份：HMAC 派生匿名练习 ID，不暴露父母微信 OpenID；同一家庭再次登录生成同一 ID。它是**尚未绑定任何孩子的家庭体验记录**，不是正式学生学籍。
- 基础练习成绩允许暂存在该体验 ID 下；既有正式孩子、旧游客和微信小程序用户档案均不自动合并。多孩子家庭必须先完成正式档案绑定，避免临时记录错归属；对应正式绑定详见 Issue #103。
- guest_family 仍以 `guest_` 前缀执行现有完整考试拒绝规则；家长微信身份不能被解释成学生正式考试授权。无权限进入完整模拟或学生个人报告时显示明确的学生账号提示，禁止登录页/受保护页互相重定向循环。
- 家庭主动退出时只清除其家庭体验练习 Cookie，不擅自使浏览器中独立正式学生的会话失效。家长账号停用/会话版本撤销时，关联的体验练习签名立即不能再解析。
- 家庭到计算训练的入口使用完整浏览器导航，确保 Next.js RSC 重定向携带的 Cookie 正确安装，防止只出现空白 main 的过渡回归。
- 手机 Safari/Chrome 直接打开登录页时额外呈现「分享到微信 / 复制链接」，解决同一台手机不便扫码的问题；微信内网页使用轻量授权。
- 回归覆盖：稳定练习 ID、训练记录 POST/GET 跨页面恢复、完整卷禁止、家长退出清 Cookie、独立学生会话保持、桌面/移动真实浏览器完整链路。

## 2026-10-12 已有学生账号经 PIN 认证后关联家庭（Issue #103 阶段一）
- 家庭中心新增「关联已有学生账号」，不再要求家长重复创建孩子。
- PUT /api/family/students 要求有效家长签名 Cookie、原学生登录名或准考证号及正确 PIN；拒绝未认证、错误 PIN、管理员或停用账号。
- 绑定复用原学生 ID，旧模拟分数和计算记录不需复制或迁移；同一家庭再次绑定幂等。
- 不允许学生账号被两个不同的家长家庭同时占有。后续解绑、跨微信 AppID 关联与多孩子设备切换必须再单独验证授权与回滚。

## 家庭里多个孩子的一键学习切换（2026-10-12）

- 已通过原账号 PIN/家庭归属验证的孩子，在家庭首页直接出现姓名、年级和计算次数。家长只需点击一次孩子的卡片，系统即以该**真实孩子原 ID**开展数学计算训练，不要求每次重输 PIN。
- 当家中存在多个已关联学生时，家庭首页的「数学训练」优先提示先选孩子，而不是默认把练习写入共享家庭体验档案。未绑定孩子时保留无需填写学生资料的基础体验通道。
- `POST /api/family/active-student` 由当前家长签名会话、同源请求和真实家庭归属三重验证；返回独立于 PIN 登录的**家庭代管学生会话**。会话校验在每次使用时重查家长版本、家庭归属、学生启用状态和学生 PIN 版本，且有7天上限。
- 家长主动退出时清除家庭代管孩子的浏览器 Cookie，但不取消独立凭 PIN 登录的学生会话。家长失效、PIN 更新或家庭解绑都会即时撤销家庭代管会话。严禁拿家长身份直接执行学生完整考试，只有显式选择并验证归属的真实学生身份才拥有原有学生访问权限。
- 同源防护覆盖 Origin / Host / Forwarded proto，Cookie 使用 HttpOnly、SameSite Strict、HTTPS Secure，正式域名共享范围仅限 socthink.cn。
- 自动化分别模拟两个孩子的计算记录提交、刷新读回、切换隔离、无关家庭越权、家长退出及撤销。跨 Web/小程序统一微信主账号、解绑授权、未指定孩子的体验记录迁移仍由 Issue #103 后续完成。
