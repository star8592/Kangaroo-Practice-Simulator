# 微信登录与普通学生账号的竞赛权限一致性

2026-10-22。适用于 SOC THINK 的 Web 以及微信小程序，**所有可用数学赛事**，不限于 SEAMO。

## 产品规则

- 已验证的微信公众号/微信扫码登录家长账户可以直接进入全部**免费**竞赛、模拟和专项练习，系统自动提供稳定的家庭学习档案，不要求额外注册学生账号、填写准考证号或 PIN。
- 已验证小程序的微信用户（服务器颁发的 wx_ 会话）按同等免费账户权益使用。仍未实现原生输入/语音或分段赛制的题卷在小程序中提供 Web 入口，不通过伪造原生支持隐藏此类题卷。
- 免费身份和付费权益是两个不同维度：是否购买由可审计的服务端订阅记录决定；微信登录不会自动授予会员权益。
- 未验证的匿名游客、仅持匿名 guest_ 会话的访问者仍不得创建完整考试会话或提交正式成绩。纯浏览赛事目录不强制正式账户。
- 原有学生用户身份优先；已有学生会话不可被微信家庭引导过程覆盖。家庭账号注销或撤销后，其家庭体验身份立即失效，不得再读取历史考试记录；不同家庭数据隔离。
- 微信家长登录及家庭学习会话均为最长 30 天，并受注销、停用和会话版本撤销约束。不因练习跳转反复要求扫码。

## 工程事实

- `classifyStudentIdentity` 只将经过 `userFromSessionToken` 校验并映射出来的 `guest_family_` 家庭主体分类为有账号的学生身份；临时 `guest_` 与未认证者仍受 `exam_basic` 限制。
- 试卷页面、题目 API、创建/恢复考试会话、交卷接口共用同样的账号授权规则。所有试卷通过原有的题库有效性、定价和会话归属检查。
- 传统客户端点击试卷进行完整页面跳转，以避免 Next.js 预取缓存造成首次家庭 Cookie 设置后仍显示登录页的错误；家长已有有效会话后可直接打开。
- 小程序目录保留各赛事的训练卷，针对不支持的赛制给出 Web 继续入口，而不是认为该赛事不存在。

## 验收条件

- 从首页竞赛列表选择 SEAMO 一、二年级：已登录微信家庭直接答题、朗读、提交、显示成绩；无再次登录、准考证号/PIN。
- 美国 AMC 非 SEAMO 卷同样直接进入。另需在上线后验证袋鼠、澳洲 AMC、加拿大 CEMC。
- Chrome Desktop + Android Chrome 模拟共 14 个包含登录、练习、身份注销以及模拟交卷场景；独立 `test:exam-access` 验证匿名拒绝/家庭放行/原有学生保护；正式发布不得跳过上述测试。
