# SOCTHINK K12「小升初」资料与测评专题接入契约

- **唯一产品**：`star8592/Kangaroo-Practice-Simulator` / `socthink.cn`，沿用 `/assessments` 的 `school` 域。
- **首批地区**：中国湖北武汉；模型设计要允许全国城市、学校、考试届别扩展。
- **记录日期**：2026-10-30。关联追踪：#156。
- **当前状态**：外部来源索引已迁至 **staging-only 元数据文件**；未连接到网站正式题库、没有部署或发布。
- **不得建立**独立小升初网站、账号、支付、订单、成绩库或另一套评测引擎。

## 1. 应有的信息架构

`综合考试与测评 / K12 学业与能力 / 小升初 / 地区 / 学校 / 届别 / 学科 / 试卷 / 答案与解析`

小升初不是袋鼠数学赛事的子赛种，也不能使用袋鼠的竞赛赛制、分值和计时规则。它是 K12 `school` 下的考试主题，适用于语文、数学、英语和跨学科测评。

后续公开页面可规划 `/assessments/school/xiaoshengchu`；只有完成可用的学生答题/报告或合法来源内容后才提供实用入口。目前不添加虚假的「开始考试」「付费下载」链接。

重要用户路径：免费浏览可信目录 → 选择学校/届别/学科 → 查看版权许可的试卷或原创练习 → 学生在线作答/A4打印 → 独立教师答案与讲解 → 错题诊断/复测/长期成长记录。复用原有 `Assessment / Question / Source / Attempt / Score / Report / Solution / Simulation / Entitlement` 核心协议，题干和答案分别版本化。

## 2. 数据层次，互不混淆

| 类型 | 内部状态 | 对外权限 |
|---|---|---|
| 原站活动或招生报道 | `event-information` | 仅展示出处与活动日期核验状态 |
| 资料站列出的下载目录 | `catalog-entry` | 仅目录外链，不能冒充已取得全文 |
| 由学生/媒体回忆的试题 | `recollection` | 需核对文本与权利，不冒充官方真题 |
| 预测/模拟题 | `mock` | 清晰标「模拟」，独立于真题 |
| 第三方真题扫描件 | `source-scan` | 权利未核实不得公开分发/销售 |
| 原创、可授权、校验通过的题目 | `publishable` | 可以进入既有考试核心与权益系统 |
| 只有 2025—2026 学年标签的校内卷 | `school-year-exam` | 不能自动归为 2026 小升初游园卷 |

始终分开 `cohortYear`（2026届）、`examDate`（可能在2025年末）、`schoolYear`（2025-2026）、`publishedAt`（转载网页发布时间）、`retrievedAt`。未知用 `null` + 明确状态，绝不从文章发布年份推断考试年份。多轮游园不能只按日期归并。

## 3. 本次接入包（仓库内仅有安全元数据）

目录：`docs/data-staging/xiaoshengchu/wuhan-2026/`

- `manifest.json`：原始本地资产数量、版本、禁止迁入内容和每批记录数。
- `sources-01.json` … `sources-05.json`：外部公开网页/资料目录的标题、链接、学校提示、学科、来源类型、访问状态。
- `claims.json`：学校与来源证据，注明2026届、回忆题/活动/目录、信息日期。
- 全量均设 `rightsStatus: unverified`、`authenticityStatus: unverified`、`publishable: false`、`publicationStatus: staging_only`。它们**不能直接被导入 live questions**。

**原始私有资产不放公共 GitHub**。Windows 原始目录 `E:\新建文件夹\_cropped\_ysy_organized` 保存 180 张扫描图、808 条未经核验 OCR 分题候选、8 条人工校对试验题、2026届 A4 来源图与 SQLite 等；对外不提供扫描字节、公式/题干全文、付费版权资料、学生信息、微信密钥或本地访问凭据。

## 4. 接入架构（复用单体核心）

```text
外部来源/原始截图 (private)
  → Source provenance / 真实性与授权队列
  → Paper identity & version (学校、地区、届别、科目、场次)
  → OCR / 几何原图裁剪 / 公式 LaTeX / SVG 重绘 (private)
  → 逐题原图比对、答案独立解题核验、去重
  → publishable-item gate
  → SOCTHINK Assessment Core (原有登录、考试、计分、报告、会员)
```

源文件只由授权的内部数据迁移服务读取；前端与构建产物绝不打包私有原图、答案解析或学生数据。对于一题多版本，保留 `canonicalQuestionId`、`revision`、`sourceEvidence[]`、`paperId`、`sourcePage`、`cropBBox`、`answerVersion`、`diagramAssetId`、`geometryReview` 与 `rightsStatus`。学生卷和教师答案必须各自生成，并防止权限与题目答案泄漏。
