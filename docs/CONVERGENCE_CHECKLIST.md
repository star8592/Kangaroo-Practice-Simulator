# v1 Convergence Checklist

## Goal

Stop architectural expansion and move to a stable product loop.

## Completed foundations

- Competition, Arithmetic, Solution separated as domains
- Student Profile as shared capability layer
- Learning Event pipeline defined
- Existing systems connected through adapters

## Remaining before v1 freeze

### 1. Arithmetic Domain

- Move calculation logic into domain boundary
- Keep existing API compatibility
- Add diagnosis and next-session recommendation

### 2. Profile Integration

- Connect real exam events
- Connect arithmetic sessions
- Connect solution feedback
- Generate explainable student reports

### 3. Product Validation

- Login flow
- Exam flow
- Arithmetic flow
- Report flow
- Admin flow

## Freeze rule

After these items pass:

- no more large architecture changes
- new competitions become plugins
- new training modes become domain extensions
