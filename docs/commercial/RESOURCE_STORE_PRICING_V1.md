- 本地私有工作区独立制作 3 件原创完整资料草稿（数学3–4年级、数学5–6年级、SQL），哈希、大小、原始资料类型见 data/discovery/original-product-drafts-20261031.json；具体内容未进入公开 Git。

## 数据分层（只保留一条权威商品订单主链）
1. **source_reference**：官方/许可第三方的来源链接、机构、年份、考试类型、原网页发布日期及核验时间；免费的外部导航。
2. **practice_ready**：现有练习卷，维持原服务端考试权限；不据此推导商用授权。
3. **digital_product_draft**：拥有版权或可商业转售权利且已生成完整文件的待售商品；有 preview、合法权属、SHA256、文件大小、明示价格，但尚无付款按钮。
4. **active_digital_product**：仅在经真实校验的单一正式账本、支付、通知、幂等发放、签名下载和购买记录均通过后开放。不要生成虚假可售库存。

## 售价原则（早期验证价格，不是市调结论）
用户默认以人民币直接购买单件；不引入充值积分和余额系统。
- ¥1：小型原创表格/知识清单/基础练习（如原创12题）。
- ¥2–3：一份完整原创题卷 + 答案 + 逐题解析。
- ¥3–5：有明显方法讲解的专题练习包。
- ¥6–9：三年内综合专题包，不以直接包装免费真题作为商品。
- ¥9–19：原创系统化知识训练与复盘工具包。
以定期可复核的购买转化、复购、用户反馈与制作成本调整价格；**不得按“最新版”或“稀缺真题”营销未核实材料**。

## 买家体验与销售链
公开目录 -> 实际目录/文件样例/适用对象/版本/边界 -> 明示人民币价格 -> 微信登录 -> 微信支付原生订单 -> 服务端通知及主动查单 -> 权益授予 -> 原账号查看订单 -> 受控私有文件下载。
- 每笔订单 price_fen 由服务端正式商品记录确定；客户端不得提交任意价格或“已支付”。
- 交付前计算文件 SHA256、大小和安全路径；交付时再次校验；不能将数字文件放在 public/ 目录。
- 订单 idempotency key 防重复收款与重复发放；只消费已核实 paid 状态，不启用另一个收费账本。
- 售后明确数字内容交付后原则上不支持无理由退款，但法律规定的未交付/严重不符等消费者权利不可排除。

## 持续扩充规则（2024–2026）
- 每个考试先查主办方最新赛制；只有真实可获得且有来源的记录才计库存。
- 来源去重：主办机构 + 考试 + 年份 + 级别；保留原网址及最近核验日期。
- 先按官方来源索引入库，再产出独立原创解析与训练；版权可售状态须有明确证据而非“网上搜到”。
- 题目与答案自动化校验：数学数值/选项、SQL数据库执行、语言内容人工与模型交叉复核；有问题不开放付费。
- 新资料先进入可回滚的批次，不靠覆盖旧数据库，也不在前台展示空商品。
