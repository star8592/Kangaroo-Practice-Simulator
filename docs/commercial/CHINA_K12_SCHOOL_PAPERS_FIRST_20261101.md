# SOC THINK 中国 K12 校内考试真卷主库：2026-11-01 纠偏版

## 业务定义

K12 指中国小学、初中、高中的校内与区市省考试资源。必须优先收集语文、数学、英语、物理、化学、生物学、历史、地理、道德与法治/思想政治、科学和学校实际考试涉及的其他学科。重点为月考、开学考、期中、期末、区统考/调考、市调考、省级统考、联考、中考、高考及相关模拟。竞赛、大学、英语等级、职业资格仍是独立业务，不得作为国内K12采集业绩。

现有唯一小时采集任务2026-11-01已调整为至少80%有效工作投向国内K12，其他类不要求每小时都凑新增量。国际旧档案保留并去重，不继续堆积国外PDF或研究生大纲代替K12真实进度。武汉湖北为第一批地区，逐步扩大到全国城市、区县、学校及普通校和名校。

## 分类模型

- 地理：省、市、区县、学校/教研单位（只记录公开可证的机构）。
- 年级：小学1-6、初中7-9、高中10-12，注意各省学制差异。
- 学科：语数英、理化生、史地政、科学、综合、正式合卷及英语听说。适用的科目版本与教材版本独立记录。
- 真实考试：学校、区、市、省、全国、跨校联考六种层级，必须凭卷头或发布机构确认，标题带“元调”或“区”不能直接认定市统考。
- 时间：考试真实日期与学年学期分开，发布时间另记；2026-2027学年不等于2027年已考卷。2026-11-01优先本学期实际已发生的月考/期中，其次2026春期末、2026中考高考和调考，继续补2025、2024。
- 答案与格式：空白原卷、参考答案、详细解析、评分标准、英语听力音频、听说机考素材、完整页数各自记录真实性和完整度。
- 湖北合卷：物理与化学、历史与道法、生物与地理存在合卷；存为一张原卷的多科关联而不是拆成多张重复计数。2026起省级英语听说机考单独建考试组件，规范依据湖北省教育厅官方通知：https://jyt.hubei.gov.cn/norms/202312/t20231222_5013119.shtml 。

## 唯一资料流水线

学校/教育主管部门官方公开发布与合规第三方公开线索发现 → 真实考试事件/卷头/原发布机构确认 → 正常授权范围内下载文件 → 原件SHA/页码/附件/答案与听力核对 → 逐题OCR衍生与人工复核 → 结构化试卷/模考规则 → 获得必要再分发权后才公开上线。公开检索无须逐条审批；第三方受限下载不通过截屏OCR翻页绕过，不将公开目录/收费文档当已下载真题。

状态严格区分线索、发布方已确认、原件归档、完整试卷与答案验收、结构化训练可用、经许可公开发布。试卷实体按考试事件+卷种+学科合卷去重，不因多校转发而重复。正式商品的支付与交付是独立验收，不由资料采集器推断。

## 此刻真实基线

已有433条武汉K12第三方页面目录（旧六年级99+新增334），来源主要武汉教育资源网，既有数据本身只涵盖小学和一小部分初三语数英，物理化学生物历史地理政治、初一初二、高中几乎缺失。其链接目前不能计为已下载完整原卷。运行 scripts/build_china_k12_priority_20261101.py 可根据真实元数据筛选优先复核队列，并输出 data/discovery/china-k12-school-exam-priority-20261101.json；独立测试坚持所有来源未核验状态不会被升级为已入库。

增补的八个来源入口详见 data/discovery/china-k12-source-entrances-20261101.json，涵盖武汉教育云、中考官方政策、2026湖北中考各科第三方页面、武汉高三四调九科目录、武汉高一下期中全科商业资源站。八个入口只是链接与来源类别，新增实际取得完整卷=0。官方武汉教育云可展示学段/学科/期中期末分类，但当前网页显示0条，不能假称导出了试卷。对于明确声明独家学校版权的资料仅作发现入口。

## 验收指标

主指标是本年度去重的真实完整卷及答案校验数，按年、学段、年级、学科、区市省和考次统计覆盖率、缺页比例、英语听力完整度、题目复核率与已上线可训练数。公开页面链接数、搜索关键词次数、招生大纲或海外 PDF 下载量不得顶替“国内K12已收真卷”的计数。下一轮优先2026最新期中期末/区调考，增加初一初二、高中及理化生史地政真实来源，而不是重复扩充只含小学语数英的目录。
