# 七大资料栏目年度选择规则（2026-10-31）
本文件是七条独立资料生产线共同遵循的年度优先顺序。它不创建第八套目录，也不替换唯一商品/订单/支付服务。

## 不再默认批量搜集2024–2026
- 第一优先：适用考试年度2027。先获取官方2027公告、报名规则、考试大纲、题型、时长、可公开样题；已发布则据此原创制作2027备考商品。
- 第二优先：适用考试年度2026。2027尚未公布时，2026是可核实的最新已发表考试资料；商品标注“2026现行规则参考/2027待官方核对”，不能把2026旧题称为2027真题。
- 2025及更早：常规搜集暂停，仅为某个问题的历史变化对照或明确客户需要再入库。
- 2027即使已发招生/考试公告，2027真实试卷可能尚未举行或尚未公开；必须分别标注 examYear / paperYear / publicationYear / ruleVersion，严禁将原创模拟、旧卷重排或网上传闻标为“2027原卷”。
- 职业技能、兴趣/能力栏目没有统一考试年度：优先更新2027适用的现行技能、内容与权属，paperYear=null；不捏造官方2027考试。

## 当前已核查的2027官方规则示例
- 2027考研：教育部2026-09-21印发《2027年全国硕士研究生招生工作管理规定》：https://www.moe.gov.cn/srcsite/A15/moe_778/s3261/202609/t20260923_1451734.html
- 2027国考：2026年10月官方招录公告：https://shanghai.chinatax.gov.cn/xxgk/rsxx/202610/t481763.html
- 其余五大领域逐项目查询 2027 官方版本；没有依据就使用2026，不混淆版本和权利许可。

## 七线同一调度循环
每线：2027权威来源搜索与核验 → 2026备份资料核对 → 制作真实原创题目/解析或技能训练 → 实际文件SHA/质量与版权核查 → 推入现有唯一商品草稿与待售流程 → 正式支付、授权和交付验收前保持不可购买。
七线相互失败隔离，可并行搜集/生产；只保留一个汇总提交与正式部署通道。
每轮报告 7 行，分别统计2027已核对、2026回退、2027尚未公开、原创商品草稿、正式可售数，不用链接数量冒充商品。
