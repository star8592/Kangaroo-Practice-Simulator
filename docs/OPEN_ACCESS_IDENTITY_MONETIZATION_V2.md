# 袋鼠数学平台 V2：开放训练、渐进身份、按需付费

状态：设计已确认，第一阶段代码实施中；尚未上线。仓库：star8592/Kangaroo-Practice-Simulator。范围：网站、微信小程序、共用 API。

## 用户旅程
1. 打开网站/小程序直接浏览年级、计算、竞赛；不出现登录墙。
2. 匿名开始真实训练、考试；保存答题草稿；提交后免费查看分数、正确率和基础错题。
3. 深度报告/高级题解先展示明确的价值预览；可单次购买或按月订阅。
4. 需要跨设备保存、管理孩子或找回订单时，才绑定身份。微信端使用 wx.login + 后端 code2Session，失败不阻断公开训练。

## 服务边界
- Identity：账号、微信 appid/openid 绑定、登录会话；不得根据昵称合并。
- Attempt：匿名或实名考试/计算记录、不可变提交快照、恢复与归并；必须验证匿名会话所有权。
- Order：订单、支付渠道、金额币种、幂等键、退款和对账。
- Entitlement：单次报告范围、会员有效期、购买来源、撤销状态。
- Report：免费基础结果、付费深度报告；权限必须在服务端验证。

## 当前源码审计
- apps/miniapp/src/services/api.ts 旧版 401 全局清 Token 并跳登录。
- 首页、计算、竞赛、赛事和个人中心旧版依赖 goLoginIfNeeded。
- /api/auth/miniapp/guest 已存在，可签发短期游客会话；实际线上可用性尚未验证。
- /api/miniapp/arithmetic/session 要求 student 会话；不能简单删掉登录判断。
- 试卷提交和训练写操作不得在 401 后自动重试，避免重复写入或跨身份提交。

## 分期交付
P0 线上环境、游客错误码、微信请求域名与发布包核对。
P1 Web/小程序匿名浏览、真实计算、竞赛、基础结果；草稿持久化和会话异常恢复。
P2 微信静默身份、网站统一账户、匿名记录安全归并、跨设备同步。
P3 单次深度报告、月度会员、订单和权益；微信支付参数由项目方最后提供。
P4 灰度、真机 E2E、支付验签/退款/幂等、回滚演练与发布。

## 阻断性验收
- 不登录完成 10 道计算题、提交并查看结果。
- 不登录完成竞赛试卷、提交并查看基础成绩。
- 401、断网、重启后已有答案不丢失。
- 匿名转正式身份不串号、不重复迁移。
- 微信登录失败不阻断游客训练。
- 支付回调验签、重复通知幂等、退款撤权、订单找回通过后才上线支付。
- 所有改动先独立提交，保留回滚版本，不覆盖其他工作树。
