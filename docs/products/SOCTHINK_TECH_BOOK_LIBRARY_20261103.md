# SOC THINK 技术书库：独立实现与首批交付

日期：2026-11-03  
位置：现有技能实训模块 /skill-labs/books  
状态：2026-11-03 PR #264 已合入 main，生产部署 SHA 8de7075de9c60c5db566a71aad842e122ebdc4b5 与公网抽查均已通过。

## 目标
把“发现一本书”变成“官方来源 → 原创中文导读 → 技术资料 → 真实技能实训 → 可复用成果”的路径。该模块属于 SOCTHINK 现有 Next.js / 模块化单体，不建立另一套账号、支付、会员、CMS 或搜索权威库。

## 第一期实际实现
- 9 本原创编辑精选书目（非 Hacker News 排名，非完整第三方数据集）。
- 每本记录：书名、作者、难度、中文介绍、推荐理由、练习建议、阅读入口类型、官方/开源资料链接、关联的现有实训入口。
- 书库列表 GET 查询与主题筛选；静态生成的独立书籍详情和 canonical URL；Sitemap 收录。
- 现有 /skill-labs 页面内新增入口；不改变全站顶层导航、不改身份与支付接口。
- 单独的目录合同测试 scripts/test_tech_books.ts；不增加无关发布门禁。

## 借鉴与原创边界
思路参考 HackerBooks（hackerbooks.org）和中文项目 joeseesun/hackerbooks-cn；**未复制它们的 JavaScript、CSS、翻译、评论、封面、数据库或排行**。页面和数据模型由 SOC THINK 自主实现。
书目是书籍事实与我们独立撰写的简短评论，外链指向作者/项目/出版社页面。外部页面公开可读不代表可复印、翻译后出售、镜像全文或转载插图。尤其 Python Data Science Handbook 与 Eloquent JavaScript 的文字存在非商业使用限制；商业站点仅做原创简介与合法外链。

## 后续数据扩展
1. 先以出版社/作者/官方仓库验证书名、版本、作者和访问权限，再生成稳定 slug。
2. HN 公开讨论可作为“发现候选”的情报；每条推荐都应提供 HN 原帖 URL、时间、真实评价语境，并区分正评/批评。不得把提及次数写成推荐评分。
3. 若导入第三方结构化数据，先核实其数据许可证和转载边界；任何高频数据管道应独立后台运行，不让外部网站故障阻塞 SOC THINK 页面或支付。
4. 将未来的自有实战课程、下载包/SKU 绑定既有商品权威记录；没有真实交付与付款验收前，不显示付费购买按钮。

## 验收
- 书库入口和各详情匿名访问 200，SEO title/canonical、Sitemap 有效；未知 slug 返回 404。
- 搜索中文介绍、英文书名与作者有结果，主题筛选无跨类。
- 所有官方外链核验；书籍权利类型明确，网站不提供未经许可的书籍下载。
- 移动端单列、桌面卡片清晰，内容不溢出。
- 内部所有关联学习路径能真实进入已开放的模块；Rust 尚无专项实验，明确说明。
- CI 成功后才考虑合并；生产最终以现有唯一发布器 SHA 回执和真实浏览器检查为准。

## 经营指标（数据接入后才能测量）
搜索词、书籍页自然曝光/点击、书籍→实训点击率、实训完成、商品页访问、实付转化。当前**未部署新的业务统计采集**，不展示虚构转化率。

## 官网下载入口（2026-11-03 增量）
- 原始 HackerBooks 中文站提供 Z-Library 的**外部搜索链接**，不是提供可验证的站内正版 PDF 仓库。本产品不复制其 Z-Library 入口。
- 书籍索引与实际可下载文件严格分开。第一版 9 本书目，站内托管的第三方书籍全文：0，本轮官方整书 PDF 直接链接：1。
- 《Dive into Deep Learning》官网 https://d2l.ai/ 的免费 PDF https://d2l.ai/d2l-en.pdf 经真实请求验证存在，网页仅提供**原站外链**，不镜像、不收费转售。其他书籍保留官方在线阅读或出版商购买入口，未核验时不显示 PDF 下载按钮。
- 外部免费阅读 ≠ 已获得全文再分发或付费镜像许可；第三方数据、封面、评论与 PDF 的授权应分别核验。
- 后续书目增加时可复用 `officialDownload` 结构，只有经确认的作者、出版方或明确授权的平台可以填入。保持检索免费，依靠本站原创实训及可验证交付增值收费。
