# Chinese Math Competition Translation Standard

## Objective

Create official-quality Chinese versions of international mathematics competition questions.

## Rules

1. Preserve mathematical meaning exactly.
2. Do not modify numbers, formulas, conditions, diagrams, or answer choices.
3. Keep original English content as source data.
4. Generate Chinese exam version separately.
5. Generate explanation and teaching metadata separately.

## Required outputs per question

- localized.en
- localized.zh
- solution.zh
- knowledge tags
- validation status

## Terminology examples

| English | Chinese |
|---|---|
| prime number | 质数 |
| factor | 因数 |
| multiple | 倍数 |
| fraction | 分数 |
| ratio | 比 |
| perimeter | 周长 |
| area | 面积 |
| volume | 体积 |
| probability | 概率 |

## Quality checks

- number consistency
- formula consistency
- option consistency
- answer consistency
- difficulty preservation
